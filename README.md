# COD4 / IW4X / COD OL — 逆向分析工作区

按 代码 / 文档 / 服务器 / 工具 四大类组织，不含任何游戏原始资产。

| 顶层 | 内容 |
|---|---|
| code/ | 实现代码（Python 模块、C/C++ 源码） |
| docs/ | 分析文档与报告 |
| server/ | 自建服务器（战斗服 / 大厅 / IIPS / 鉴权）相关代码与文档 |
| tools/ | 分析与操作工具 |

其中 tools/py/oneoff/ 收拢全部一次性脚本（原 misc / tmp / z7 等），dis / find / test 保留独立分类。

## 说明

- 不含游戏本体文件（.ifs / .iwd / .ff 等）、压缩包，以及任何受保护的启动基线目录。
- 单文件均小于 5 MB。
