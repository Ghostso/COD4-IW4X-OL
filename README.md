# COD4 / IW4X / COD OL — 逆向分析与本地链路复原

面向《使命召唤 OL》（build 1649370 / 3.19）的**协议逆向、启动链复原与自建服务端**工作区。
仓库只收录**文档、代码与工具**，不含任何游戏原始资产。

## 目录

| 路径 | 内容 |
|---|---|
| `code/` | Python 模块（3,245）与 C/C++ 源码（756） |
| `docs/` | 全部分析文档：实验记录、战斗服、基线判定、构建风险、交接报告 |
| `server/` | 自建服务器相关：大厅 lsg、鉴权、IIPS、战斗服（UDP 28960） |
| `tools/` | 一次性脚本（`oneoff`）、`dis` / `find` / `test` 工具组、PowerShell、Lua |
| `baseline/` | **固化启动链的未受保护副本**，附使用说明与内存转储时机 → [baseline/README.md](baseline/README.md) |

## 关于基线

受保护基线（`CODOL_VERIFIED_GOLDEN_20261019`、`REF_LOBBY_KIT`）是**固定范本**，
不进入本仓库，也不应被直接运行或改写 —— 它是判定"行为变了还是环境变了"的参照系。
需要动手时用 `baseline/unprotected-kit/` 这份可读写副本。

## 方法论

- **本地逆向为最高权威**：从真实客户端抓到的字节、从游戏文件解出来的数据，优先于任何外部实现。
- 外部参考按可信度排序：IW4X 优先于 CoD4X；其他项目（含 ol-mod）只作同族交叉参考，数值不得直接搬用。
- 每个结论都要挂证据：字节范围、调用边、可复现的抓包或清单哈希。

## 不做什么

- 不发布游戏本体、地图、音频等受版权保护的资产
- 不发布私钥、证书与任何运行凭据
- 不把"模拟客户端通过"当成"真实客户端通过"
