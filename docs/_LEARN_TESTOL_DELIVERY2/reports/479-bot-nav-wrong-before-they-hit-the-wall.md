## 八、关键结论

1. **⭐⭐⭐ "原行为：目标与本机**不同连通分量**时返回 `straight = true`，让 bot **朝不可达目标直线走** ⇒ 走进墙/卡在出生区，只能靠卡死升级反复补救 —— **这是撞墙之前就错了**"`** ⇒ **"修那个目标比修那个碰撞更早"`** —— 与 §467/§477 同族；而修法是**一次 BFS 现算本机所在的连通分量**并在其中挑**离本机最远的可达节点**当临时目标 ⇒ **"只有真的连图都没有时才退回直线"`**（那个 `straight` 现在只覆盖孤立节点）。
2. **⭐⭐⭐ "刀CI 的 BFS 落在 `route.empty()` 的每帧路径上：目标一旦不可达就永远不可达，于是 **12 个 bot × 每秒 10~20 次**，每次都重新 `std::vector` 分配 + 整图遍历 ⇒ **恒定的堆分配与 CPU 开销**（这才是『稳定地卡』的来源，不是人机数量）"`** —— **独立量化：`120..240` 次/秒 × `559` 节点 = `67k..134k` 节点访问/秒，而每次还有一个分配**；而"刀CT 只加一个缓存，不动那个语义"`。
3. **⭐⭐⭐ 那个单槽缓存（`destination`/`bestNode`/`resolved`）只在同一个 bot 反复问同一个目标时有效 —— 而那正是那个场景**（目标不可达 ⇒ 每帧问同一个）⇒ **"一个数据结构的形状适配一个访问模式"`**；`seen`/`queue` 的 `thread_local` **避免一个互斥量**（与 §471 的 `thread_local const char *` 同族）。
4. **⭐⭐⭐ "刀CT 去掉了分配但保留了 `O(V)` 的清零（`seen.assign(nodeCount, 0)`），而那比一次分配便宜得多"`** —— 一个**精确的范围界定**。
5. **⭐⭐⭐ `verticalWalkMinPlanar = 64`：ZM 侧那个字段默认 `0`（"零 = 禁用"，第四次）；MP 侧 `64`** ⇒ 因为**"一个被编写的对战地图没有障碍/协商表，所以同一道门也拒绝了它真正的楼梯与坡道，而留下一个不连通的图"`**。
6. **⭐⭐⭐ 那次测量（`2026-10-12`，`mp_crash_tropical`）**：`64` 下**连通分量 `8 → 2`、最大分量 `239 → 312`（共 `316`）、可达节点对 `29,013 → 48,522`，而那四条 XY 重叠的地板链接（平面 `6..28`）仍然被拒绝**，`from=67 → dest=225` **从无路由变成一条 `1727` 单位的** ⇒ **独立验证：那四条 `6..28` 全部 `< 64` ⇒ 全部被拒绝 ✓**（与 §478 的 `120 − 24 = 96 > 72` 同族）。
7. **⚠ 一个未闭合**：`29,013` / `48,522` 的精确语义（有向/无向、是否含自身）未说明 —— 若按无向对算，`239 → 312` 的最大分量对应 `28,441 → 48,516` 个无向对，与那两个数**接近但不完全吻合**（`29,013` 略大于 `28,441`）⇒ **标注为待核**。
8. **⭐⭐⭐ "那三个战术标记（`claymore`/`grenade`/`javelin`）描述一个站立的节点携带一个建议，不是一个演员必须执行的遍历"`** ⇒ **"同一个字段两种语义"`**（真姿态 vs 建议），由注释划清界线 —— 与 §473 的"保留为出处但从不使用"同族。

10. **✅ 已闭合（本轮实测）**：`SvBotNavParseCsv` 建的是**有向** CSR（`adjacencyStart[n+1] = adjacencyStart[n] + neighbours[n].size()`，`.hpp:56-57` 也写明是 "neighbours of node i"），而 `sv_zm_navgraph_mp.cpp` 的 `SvZmNavGraph` 期望**无向** —— 但**实际 CSV 全部对称**。我实测四个文件：`mp_nuked_wp.csv` 235 节点 / 738 链接 / 0 自环 / 0 重复 / **0 不对称**；`mp_rust` 192/554/0/0/0、`mp_overgrown` 558/1890/0/0/0、`mp_crash_tropical` 316/956/0/0/0。⇒ **那个"有向 CSR 装进无向结构"在数据上是无害的**（对称 ⇒ 每条边恰好两个方向各一次，正是无向 CSR 的形状）。**§4.5 与 §4.4 里我标的"可报告的不一致候选"降级为：不是缺陷，只是两个模块用了不同的构造写法。**
