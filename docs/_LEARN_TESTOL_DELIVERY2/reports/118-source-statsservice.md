| 步骤 | 公式 | 说明 |

## 九、结论

```
`slot = rating/6000`（封顶 33）⇒ `段位 = slot/3`（11 = 战神）⇒ `屏幕分 = rating − min(slot,33)×6000`
        ↓
★★★ 加 72,000 ⇒ 界面从 3,957 变成 **1,244（更错）** ⇒ 线性假设被推翻
        ↓
★★★★★ 正解：**基数 `198,000 = 33 × 6000`**
```

### 2. ★★★★★ **`lb 1000` 缺 11 个字段会导致 1200 秒的"未定级"缓存**

### 3. ★★★★★ **两个榜的 `name` 编码**相反**（玩家榜 base64 / 战队榜原样 UTF-8）**

### 4. ★★★★★ **`4/4` 与 `4/13` 都是 4 个类型化字段**（更正报告 117）

### 5. ★★★★★ **槽位 0 有前导/尾随两种语义**（一个"全区排名永不显示"的嫌疑点）

### 6. ★★★★★ **`MaxRows = 100`**（客户端要 101 ⇒ 必须钳制,超发走出数组）

### 7. ★★★★ **列值必须落在显示域内**（`col1 ∈ [1,70]` / `col9 ∈ [1,18]`）
