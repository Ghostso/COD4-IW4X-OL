## 一、★★★ `decode_cmdline`（第 348–363 行）

```python
def decode_cmdline(h, addr):
    """读取 CreateProcessW 的 lpCommandLine (LPWSTR)，容错版"""
    try:
        raw = rpm(h, addr, 4)
        if len(raw) < 4:
            return "<short:%d:%s>" % (len(raw), raw.hex(" "))
        ptr = struct.unpack("<I", raw)[0]
        if not ptr:
            return "<NULL>"
        raw2 = rpm(h, ptr, 1024)
        if not raw2:
            return "<empty_ptr:0x%X>" % ptr
        text = raw2.decode("utf-16le", "replace").split("\x00")[0]
        return text if text else "<empty>"
    except Exception as e:
        return "<err:%r>" % (e,)
```

★★★ **⇒ **两层解引用**（`CreateProcessW` 的第 2 参是 `LPWSTR`，但栈上存的是它的指针）：**
```
第 1 层：读 [addr] 4 字节 → ptr
第 2 层：读 [ptr] 1024 字节 → UTF-16 字符串
```

★ **⇒ 五种错误标记：`<short:…>` / `<NULL>` / `<empty_ptr:0x…>` / `<empty>` / `<err:…>`。**

★★ **⇒ 上限 1024 字节（512 个 UTF-16 字符）。**

## 三、★★★★★ 镜像的实际构建（第 386–399 行）

```python
KEY_MAX = 0x40000                       # 262,144
IMG_LEN = 4 + KEY_MAX * 4 + 0x8000      # 4 + 1,048,576 + 32,768 = 1,081,348
b = bytearray(IMG_LEN)
struct.pack_into("<I", b, 0, 0x40)      # ★ 魔数
tbl, rec = 4, 4 + KEY_MAX * 4           # tbl=4, rec=0x100004
entries = {}

def put(key, val):
    nonlocal rec
    entries[key] = rec
    struct.pack_into("<I", b, rec, len(val))      # ★ 写 len
    b[rec + 4:rec + 4 + len(val)] = val           # ★ 写 value
    rec += 4 + len(val)
    rec = (rec + 15) & ~15                        # ★ 16 字节对齐
```

### ★★★ 完整布局

```
偏移            大小              内容
0x000000        4                 魔数 0x40
0x000004        0x100000 (1 MB)   跳转表：KEY_MAX 个 DWORD
0x100004        0x8000 (32 KB)    记录区：(u32 len)(value)，16 字节对齐
                总计 1,081,348 字节
```

★★★ **⇒ `IMG_LEN = 4 + 0x40000*4 + 0x8000 = 4 + 1,048,576 + 32,768 = 1,081,348`。**

★ **⇒ 每条记录：`(u32 len)(value)`，然后**16 字节对齐**。**
