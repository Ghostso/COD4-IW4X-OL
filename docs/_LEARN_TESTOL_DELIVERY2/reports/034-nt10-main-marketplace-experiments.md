### 1.1 ★★★ 老外的原始依据（第 1516–1525 行，逐字引用）

```python
# 依据是老外自己的游戏服务端代码 `src\game_server\ClientProcessPatches.hpp:250-268`，逐字：
#   "OWN EVERY ITEM, without sending a single extra inventory byte.
#    The inventory reply is capped at 8,460 records by a 512 KB buffer the client passes
#    per task, the catalogue is 21,753 ids, and the client does NOT page -- told 19,900
#    existed while receiving 8,460 it never asked for the rest (measured 2026-09-03).
#    So no amount of work on the wire can deliver the catalogue.
#    It does not have to. ... That resolver already has an 'owned without being in the
#    inventory' branch, and the branch is guarded by a predicate with exactly ONE caller

#    quantity -1, for every item the inventory did not carry."
```

★★★★★ **⇒ 五个精确数字/事实：**
```
① 库存应答上限 **8,460 条**（客户端每任务传 **512 KB** 缓冲）
② 目录共 **21,753 个 id**
③ ★ 客户端**不分页**（被告知 19,900 存在，收到 8,460 后**从不请求剩下的**）
④ ⇒ **"no amount of work on the wire can deliver the catalogue"**
⑤ ★★★ 但不必 —— ownership resolver 有"**owned without being in the inventory**"分支，
   其谓词**只有一个调用者（它自己）** ⇒ 强制为真即让所有物品显示已拥有（quantity **-1**）
```

★★★ **⇒ 这是**架构级的洞察**：**
```

        ↓

        ↓
客户端自己有一个"已拥有但不在库存里"的分支
```

### 1. ★★★★★ 这是一段**方法论典范**：五轮反复，每次都用单变量
