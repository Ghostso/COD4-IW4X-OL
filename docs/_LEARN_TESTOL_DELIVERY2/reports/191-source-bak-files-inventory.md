# 191 · `.bak` 文件清点：9 个备份副本的存在与含义

## 一、范围

本报告记录 `source\src\game_server` 下的 `.bak` 文件，**这些不是交付内容的一部分**。

## 二、实测清点

```text
sv_snapshot_mp.cpp.bak-20261009-scopeidle   1,405,567 B
sv_main_mp.cpp.bak-刀CM                       623,038 B
sv_main_mp.cpp.bak-noautonuke                 620,062 B
sv_main_mp.cpp.bak-刀CR                       619,916 B

sv_main_mp.cpp.bak-刀CO                       618,392 B
sv_main_mp.cpp.bak-刀CP                       615,622 B
```

共 **9 个**，其中：

- `sv_snapshot_mp.cpp` 一份（`scopeidle`，2026-10-09）；
- `sv_main_mp.cpp` **八份**（`刀CM` / `noautonuke` / `刀CR` / `刀CN` / `刀CS` / `刀CQ` / `刀CO` / `刀CP`）。

## 三、与主文件的尺寸关系

```text
sv_snapshot_mp.cpp        1,466,951 B
  其 .bak                   1,405,567 B     差 -61,384（-4.2%）

sv_main_mp.cpp              657,426 B
  最近的 .bak（刀CM）       623,038 B      差 -34,388（-5.2%）
  最远的 .bak（刀CP）       615,622 B      差 -41,804（-6.4%）
```

**主文件都比备份大**，说明备份是**较早的迭代**，而主文件在持续增长。

## 四、八份 `sv_main_mp.cpp` 备份的命名规律

```text
刀CM → 刀CN → 刀CO → 刀CP → 刀CQ → 刀CR → 刀CS    （单字母序列，跳 CM→CN→CO→CP→CQ→CR→CS）
另有一个 noautonuke
```

**这是一个递增的修订序列**（中文"刀"是"刀次"的意思，即"第 N 刀"）。字母从 CM 到 CS 是连续六个，加上 CM 之前的状态与一个特殊实验（`noautonuke` = 无自动核弹）。

`noautonuke` 的尺寸（620,062）介于 `刀CM`（623,038）与 `刀CR`（619,916）之间，说明它是在这段时间内做的**一次分支实验**，之后回到了主线。

## 五、这些文件在研究中的处理

### 5.1 它们不是交付内容

`MANIFEST.sha256`（若存在）与 `preflight.ps1` 检查的是原始清单；`.bak` 文件是**编辑过程留下的**，不属于交付契约。

### 5.2 它们有诊断价值

**八个连续修订 + 一份主文件** 构成一个可以 diff 的序列：

```text
刀CM vs 刀CN vs ... vs 主文件
```

**每一次"刀"都是一次具体的修复**，而它们的差值就是那些修复的规模（从 623,038 到 619,916 有增有减，说明并非单调增加）。

### 5.3 但不应把它们当作源码的一部分来学

本报告的结论：**主文件（`sv_main_mp.cpp` 657,426 B）才是要学的**，`.bak` 只用于必要时对照某次具体改动。

## 六、此前会话记录中的对应做法

之前的会话记录里有：

> 「把包根那 6 个 .bak 文件删掉，并记下它们是上一轮的遗留，不属于交付包。」

即：**包根的 `.bak` 已被清理**，而**源码目录里的这 9 个仍在**。

**两者性质不同**：

- 包根的 `.bak` 是**上一轮误留**（用户明确要求删除）；
- 源码里的 `.bak` 是**上游编辑过程的一部分**，属于交付包原样。

## 七、关键结论

1. **9 个 `.bak` 全在 `server_mp` 下**，包根已无。
2. **主文件都比备份大**，说明备份是较早迭代。
3. **八份 `sv_main_mp.cpp` 构成一个可 diff 的修订序列**，但**不应当作源码学习的一部分**。
4. **`noautonuke` 是一次特殊分支实验**，之后回到主线。

## 八、未闭合点

- 八份备份的具体差异未逐一 diff（不在学习范围内）。
- `MANIFEST.sha256` 是否收录这些 `.bak` 未核对。
