## 3. 风险加权解决率重算

- 旧总权重 = 91（E-15）
- 新增权重 = 3 + 1 + 8 = 12
- 新总权重 = 103
- 新增加权得分 = 3x1.0 + 1x1.0 + 8x0.0 = 4
- 新加权得分 = 32 + 4 = 36
- 风险加权解决率 = 36 / 103 = 34.95%（约 34.9%）
