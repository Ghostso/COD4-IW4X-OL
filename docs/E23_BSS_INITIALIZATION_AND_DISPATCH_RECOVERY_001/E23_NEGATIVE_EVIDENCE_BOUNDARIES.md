# E23 负向证据与边界

> 纪律：静态搜索未命中 ≠ 全局不存在。以下每条都注明搜索范围与未覆盖区域。

## 1. 已执行的否定搜索

| # | 搜索 | 范围 | 结果 | 边界声明 |
|---|---|---|---|---|
| N1 | 五地址的 VA 形式 4 字节精确匹配 | 整个恢复镜像文件 | 5 个地址均为 0 次（RVA 形式：`0xA85640` 命中 1 次，其余 0 次） | 覆盖所有原始字节；不覆盖运行时构造的指针 |
| N2 | 五地址的 rel32 `E8` 调用 | 整个 `.text`（`0x001000..0x7AD90B`） | `0xA85AD0`=1、`0xA85640`=36、`0xA85BE0`=96、`0xA87830`=125、`0xA878A0`=96 | 未覆盖 `E9`/`FF /2`（间接）与 `.tvm0` 中的调用 |

| N4 | 向五地址的写指令（`mov [reg],imm`） | 由 N1/N2 推出 | 0 处 | 它们是代码地址，本就不可能被写入 |

## 2. 未覆盖区域（明确的盲区）

1. **间接调用**（`FF /2`、寄存器目标、`jmp [table+idx*4]`）未做全量目标推断；本轮只做"地址是否被作为立即数引用"的判定。
2. **`.tvm0` 内部** 的调用图未闭合：`0xDF4A028`、`0xDF9AA45`、`0xDF6216D`、`0xDF6F97C` 等入口仅登记，未深入解码。
3. **运行时构造的指针**：若某处代码在运行期用算术生成指向五地址的指针，静态 4 字节匹配无法发现。
4. **消息码 0x81/0x83/0x84/0x85 的方向绑定**（入/出站）仍无独立字节级证据。
5. **`0xA87830` 的 `[ebp+0x18]` 24 字节输出结构**字段语义未定。

## 3. 曾被错误设为目标的问题（消解）

| 问题 | 状态 | 消解理由 |
|---|---|---|
| "五地址是否在加载期被 TLS 回调写入" | **N/A（前提不成立）** | 它们不是数据，是 `.text` 代码 |
| "五地址是否由 `.rimp` 修复" | **N/A** | 代码不参与重定位 |
| "五地址是否为 BSS 隐藏分派表" | **REFUTED** | 354 个直接调用点 + 指针扫描 ~0 命中 |

## 4. 不得用以下方式补足

- 不得用函数名、邻近字符串或地址相似性为五个目标或 `[edi+0x5F4]` 对象命名。
- 不得因五地址相邻（0x685AD0/0x685BE0/0x685640 与 0x687830/0x6878A0）就断言它们属同一 vtable。
- 不得把"认知完备率"当作协议互通完成率。
