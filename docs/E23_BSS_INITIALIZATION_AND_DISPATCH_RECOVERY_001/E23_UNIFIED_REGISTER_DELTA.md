## 2. 发现的登记簿差异（不静默改写，先报告）

**差异 D-1（I4 分母）**：
- E-21/E-22 均写 "I4 总权重 96，得分 32，完备率 33.33%"。96 的来源不可复算。
- 权威账本 `XVAL02_QUESTION_REGISTER_MIGRATION.csv` 中，`Hist_Impact==I4` 或 `XVAL01_Impact==I4` 的条目为 13 项：Q-01..Q-05、Q-11、Q-12、Q-19、Q-23、Q-28、Q-32、Q-33、Q-34。
- 逐项权重和 = 13 × 8 = **104**；得分和 = 32.0。
- 同期 `XVAL02_WEIGHTED_SCORE_RECALCULATION.md` §4 亦明确记载 **XVAL-02 I4 = 104 / 32.0 / 30.77%**。
- 裁定：**E-22 的 I4 分母 96 与总分母 219 相互不自洽**（E-21 §"重算"写 "I4 总权重 88+8=96"，其 88 又是 E-19 时点值，未随 XVAL-02 的 104 更新）。以权威复算 **104 / 32.0 / 30.77%** 为准。

**差异 D-2（总权重口径）**：
- 任务书/E-22 的 219 = XVAL-02 的 206 + E-21 的 Q-44（8）+ E-22 的 Q-45（5）… 但 E-21 原文记 "206 + 8 = 214"、E-22 记 "214 + 5 = 219"。
- 逐项复算 XVAL-02 账本 = 206（43 项）。E-21 的 Q-44 与 E-22 的 Q-45 未并入该 CSV。
- 裁定：219 = 206 + 8 + 5 在**"XVAL-02 账本 + E-21/E-22 增量"**口径下自洽，予以保留；但 I4 分母必须用 104（含 Q-33/Q-34）。
