## 19. ★★ 跨服务字节序的发现

**同一个 8 字节在两种报文中以相反字节序出现：**

```
4/13 : 0a 0e 2d 4c 6b 8a a9 c8 e7   →  按小端读 u64 = 0x0E2D4C6B8AA9C8E7
6/14 : roomChatChannelID 1800154382   →  0x6B4C2D0E
```

**`0x0E2D4C6B` 的字节反转正是 `0x6B4C2D0E`。**

**⇒ 同一个 ID 在二进制里按原序存，在文本里按反转序打印。**

**⇒ 这是文本命令与二进制字段的编码差异，不是两个不同的 ID。**
