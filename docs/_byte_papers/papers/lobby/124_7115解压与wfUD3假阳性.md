## §1 `71/15` = zlib 压缩遥测批

### 1.1 结构

`m7115_decompress.txt`：每条 `71/15` payload 开头：

```
13 08  64 00 00 00  78 01 65 cc 39 0a 80 30 10 00 …
│  │   └─ u32 len ┘  └─ zlib(deflate) ─
│  └ 08 子标签
└ 0x13 blob 标签
```

- `0x13` = blob 标签，`0x08` = 子标签，`u32 len` = 压缩后字节数。
- **`78 01` = zlib 标准头**（deflate，最低压缩档）。
- ★ **162/162 全部 `78 01`**（`m7115_vocab.txt`），**162/162 解压成功**。

### 1.2 解压后的内容 = 遥测事件流

解压后是**明文遥测事件**（和 `71/3`/`71/7` 同格式 `事件名|${时间}|值`，多条 `\n` 分隔）。`m7115_vocab.txt`：**652 条事件**。

|---|---|---|
| `UIPage` | 505 | **UI 页面访问**（末参 = 页面号） |
| `MissingLocalizedString` | 56 | 缺本地化串 |
| `ClientLoadTime` | 16 | 加载耗时（含地图名，如 `mp_firingrange`） |
| `OnBoarding` | 15 | **新手引导** |

★★ **`UIPage` 是最大宗（505/652）**：`UIPage|${TIMESTAMP_OFFSET(-21)}|<session>|<account>|${CODOID}|<pageId>`。**`pageId` 有 28 种，范围 `2..154`**（Top: `2`×113 / `121`×97 / `7`×82 / `142`×80 / `17`×42 / `107`×19 / `154`×18…）。

## §2 `wfUD3"` = 魔数 C 的 ASCII 假阳性

### 2.1 现象

`123` 普查时，某些 blob 的可读 ASCII 片段里出现 `wfUD3"`，被怀疑是密文/压缩段。

### 2.2 追查

`wfud3_cipher.txt`：真正的 `wfUD3"` 字面字节只在一处出现，且是 `88 77 66 55 44 33 22 11`（魔数 C 小端）的中间段。

`wfud3_confirm.txt`：**全语料统计**——

```
字面 'wfUD3"' 出现:   {11/4:228, 21/1:35, 21/3:13, 11/2:9, 21/12:36}
真实字节 88 77 66 55 44 33 22 11: {11/4:228, 21/1:35, 21/3:13, 11/2:9, 21/12:36}
```

**两组数字逐 task 完全一致** ⇒ `wfUD3"` **就是**魔数 C 的字节被 ASCII 正则读出来的结果：

```
0x77='w' 0x66='f' 0x55='U' 0x44='D' 0x33='3' 0x22='"'
```

★★ **`wfUD3"` 不是密文，是魔数 C 的"ASCII 外衣"。**

### 2.3 这是"字节串 vs 数值"的第三次现身

- `118`：`-695030357` vs `0xD692ADAB`（i32/u32）；
- `122`：`iHdmVUQzIhE=` b64 → `0x8877665544332211`（字节 vs 大端值）；
- `124`：`wfUD3"` ASCII vs `88 77 66 55 44 33 22 11`（ASCII vs 字节）。

**同一个魔数 C，三次被不同的"读法"套上不同的外衣。** 每次都是"看起来像新东西"。
