# ★★★★ 结论修正：`IWff0100` 与 `IWffu100` 是两种不同的加密体制

> 本轮最终的结构性结论，推翻了前面几卷的假设。

---

## 1. 完整的分派逻辑（反汇编）

```
; 读前 8 字节到 [ebp-0x10]
0x483df0  cmp [ebp+ecx-0x10], "IWff0100"
0x483dfa  jne 0x483e09
0x483e07  jmp 0x483e2b          ← ① IWff0100 直接跳到 0x483e2b

0x483e09  cmp [ebp+ecx-0x10], "IWffu100"
0x483e1a  jne 0x483edf          ← 都不是 → 错误返回

; 两者汇合
0x483e2b  read 4 bytes → eax
0x483e3b  cmp eax, 0x1cd        ← 版本必须 461
0x483e40  je 0x483e68           ← 匹配 → 继续
0x483e42  ... 打印 "283/284 %s %d %d" 错误

; ★ 关键在这里
0x483e68  read 1 byte
0x483e75  read 4 bytes
0x483e82  read 4 bytes
0x483e8f  read 8 bytes
0x483e94  cmp [ebp-0x10], "IWffu100"   ← ★★ 再次判断
0x483ea4  jne 0x483ee4                  ← 不是 IWffu100 → 跳过
0x483ed3  call 0x483b40                 ← 只有 IWffu100 才解密
```

---

## 2. 这意味着

### `IWff0100`（磁盘上的所有 `.ff`）

```
IWff0100 → 读版本(461) → 读 1+4+4+8 字节的字段 → 【不调用解密】→ 完成
```

**它根本不走 RSA / AES 链！**

### `IWffu100`

```
IWffu100 → 读版本(461) → 读字段 → 【调用 0x483b40 解密】
```

## 3. 所以之前的一切推断需要修正

| 之前的结论 | 修正后 |

## 4. 那 `IWff0100` 的内容是什么

从代码看，`IWff0100` 的文件头结构是：

```
0x00  "IWff0100"   8 字节魔数
0x08  u32 = 461    版本
0x0c  u8            （1 字节）
0x0d  u32           （4 字节）
0x11  u32           （4 字节）
0x15  u64           （8 字节）
```

**对应实测**：
```
0x00  IWff0100
0x08  461 (0x1CD)
0x0c  01
0x0d  00 00 00 00
0x11  00 91 ed 35
0x15  57 d3 c1 e2 c6 41 07 77   ← 我之前当成 RSA 密文起点
```

**`0x15` 处是一个 u64，不是 RSA 密文的开始。**

**我之前"解出 40 字节"纯属巧合 —— `RSA 私钥对任意 256 字节做运算都能得到 256 字节，其中某些会碰巧满足 PKCS#1 格式的概率是 1/65536，但在 0x2000 字节窗口里找 256 字节，有 8000 次机会。**

**8000 / 65536 ≈ 12% 的概率碰巧命中。**

**所以那不是真正的密钥 —— 是一次假阳性！**

## 5. 那么 `.ff` 到底怎么解密

`IWff0100` 分支不调用 `0x483b40`。

**说明 `IWff0100` 的内容要么是明文，要么由别的机制解密。**

**而熵 7.9998 —— 它确实是加密的。**

**所以真正的解密在别处。还没找到。**

## 8. 诚实的自我评估

**这一轮我走了一条完整的错误路径：**

1. 在 `.ff` 里滑窗找 RSA 块 → 找到（假阳性）
2. 用私钥解 → 得到 40 字节（也是假阳性链的一环）
3. 用这 40 字节做 AES → 解出头 16 字节（CFB 首块的必然结果，见下）
4. 正文解不开 → 反复调参
5. **最终反汇编发现：这个分支根本不该被走**

**第 3 步的"头 16 字节正确"是最强的误导：**
**CFB 首块只依赖 IV，只要 IV 的某个函数值碰到正确的 E(IV)，头就对。
但后面全靠 IV 的完整值，所以就错了。**

**这次的教训：必须先确认"函数会被调用"，再研究它的算法。**
