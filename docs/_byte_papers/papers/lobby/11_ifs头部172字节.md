## 2. 核心闭环（974/974）

```
tbl[4] + tail_len == 文件长度(L)
```

在全部 974 个 `.ifs` 上**无一例外**成立。

这条等式把三个概念绑在一起：

```
[4] = 尾部表起点
tail_len = 尾部表长度
L = 文件总长
```

---

## 3. 各指针的相对关系（974/974）

按 `tools/ifs_header_patterns.py` 的全量统计：

| 关系 | 结果 |
|---|---|
| `tbl[3] == tbl[0]` | **974/974** |
| `tbl[0] < tbl[4]` | 974/974 |
| `tbl[1] < tbl[4]` | 974/974 |
| `tbl[2] < tbl[4]` | 974/974 |
| `tbl[4] + tail_len == L` | **974/974** |

**结论**：`[0]` 与 `[3]` 恒等（是同一个东西被写了两次），
`[0]..[2]` 都落在载荷区内，`[4]` 之后的 2123 字节是尾部表。

### 两个样本对照

| 指针 | `ff_init_common_gametype_mp`（34.8MB） | `lf_hi_init_coop_training`（16KB） |
|---|---|---|
| [0] | `0x212C000` | `0x4000` |
| [1] | `0x2128BA9` | `0x10F8` |
| [2] | `0x2128870` | `0xD0C` |
| [3] | `0x212C000` | `0x4000` |
| [4] | `0x21344C0` | `0x4020` |
| [5] | `0x329` | `0x3DC` |
| [6] | `0x19A` | `0xD7` |
| [7] | `0x84C0` | `0x20` |
| tail_len | 2123 | 1 |

**注意**：16KB 文件里 `[0]=0x4000` 恰好等于文件内偏移 0x4000（=16384），
而 `[4]=0x4020`（=16416），`+1 = 16417 = L`。

**所以小文件里的指针是"文件内偏移"，而大文件里看起来也是偏移**：
`0x212C000 = 34,783,232 < 34,819,339 = L` ✓

**全部 8 个指针都是文件内绝对偏移**，不是相对 `0xac` 的偏移。

## 4. 清单区

在低熵样本里可读：

```
清单区 = [0xac, 0xac + tbl[0])
```

内容（`lf_hi_init_coop_training_mp_cargoship_V11.4.ifs`）：

```
偏移 0xac:
"lf_hi_init_coop_training_mp_cargoship.lst\r\n"
"hires/images/american_thread_color.iwi\r\n"
"hires/images/blackhawk_body_normal.iwi\r\n"
...（共 78 行）
偏移 0x40ac 之前: 大量 0x00 填充
末尾 16 字节: 校验
```

**清单区的长度 = `tbl[0]` = 16384 = 0x4000（块大小）**，
所以是**按块对齐的定长区**。

---

## 5. 高熵文件里的清单区

`ff_init_common_gametype_mp_V69.ifs` 的 `tbl[0] = 0x212C000`（34MB），
清单区应该也是 34MB —— 但文件本身只有 34.8MB。

**这不合理**，说明：

> 大文件与 16KB 小文件的**头部语义不同**。

### 对照实际字节

大文件的 0xac 处是明文 `.lst` + 2 个 `.ff` 路径，
到 0x148 就是 `IWff0100`。

**所以 `tbl[0]` 在大文件里不是"清单区终点"。**

### 修正后的理解

| 文件类型 | `tbl[0]` 含义 |
|---|---|
| 16KB 小文件 | 清单区总长（= 块大小 0x4000） |
| 34MB 大文件 | 载荷区终点（`0x212C000` 处开始是尾部相关数据） |

**`tbl[0]` 的语义不是固定的。**

---

## 6. 尾部表

```
[L - tail_len, L)
```

- 16KB 文件：`tail_len = 1`，1 个字节 `01`
- 34MB 文件：`tail_len = 2123`，**2123 个连续的 `01`**

实际内容只有一种值：**`0x01`**。

**语义未定。** 可能是"块是否已压缩/加密"的位图，
也可能是某种全 1 的占位。

---

## 7. 明确结论

| 项 | 状态 |
|---|---|
| 172 字节头部结构 | **完全确定** |
| `tbl[4] + tail_len = L` | **974/974 验证** |
| `tbl[3] == tbl[0]` | **974/974 验证** |
| 8 个指针是文件内绝对偏移 | **验证**（小文件 + 大文件两侧） |
| 清单区用 `\r\n` 分隔 | **验证**（591 个文件含 `.lst`） |
| 尾部表全 `01` | **验证** |
| `tbl[0]` 语义 | **未定**（大/小文件不同） |
| `tbl[7]` 语义 | **未定** |
| 0x7c 的 6×u64 | **未定**（疑签名） |
