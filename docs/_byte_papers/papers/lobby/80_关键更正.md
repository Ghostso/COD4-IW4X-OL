## 2. 这个更正意味着什么

**`lobby/74` 的结论是：**

> `[0xe59d20] = 0` ⇒ 连中间态都没到。

**但实际是 2。**

**回顾 `0x62186b` 的逻辑：**

```asm
mov eax, [0xe59d20]     ; 2
sub eax, 3              ; -1
je  → 写 4              ; 不跳（-1 != 0）
sub eax, 2              ; -3
jne → 不动              ; 跳（-3 != 0）
```

**⇒ `[0xe59d20] = 2` 时，两个分支都不走，值保持 2。**

**⇒ 模式停在 2。**

---

## 3. 2 是什么

**从 `0x6212c0` 的编码：**

```
edx = 2*bool + 3   → 3 或 5
```

**而 2 不在这个值域里。**

**⇒ 2 来自别处。**

**从 `0x6217a9`：**

```asm
cmp [0xe59d20], 0
je  skip
mov [0xe59d20], 0     ; 复位到 0
```

**⇒ 也不是 2。**

**⇒ 2 来自 `0x6217dd`（`mov [0xe59d20], eax`）或 `0x621ac0`（`edi`）。**

**而 `0x621ac0` 里 `edi = 0`。**

**⇒ 所以 2 来自 `0x6217dd`。**

---

## 4. `0x6217dd` 的上下文

```asm
0x6217d4  cmp dword [0xe59d20], eax
0x6217da  je  0x6217e1
0x6217dc  mov [0xe59d20], eax     ; ★ 写 eax
0x6217e1  ...
```

**这是一个"若不同则更新"的模式。**

**⇒ `eax` 就是要写入的新模式值。**

**⇒ 在实测里 `eax = 2`。**
