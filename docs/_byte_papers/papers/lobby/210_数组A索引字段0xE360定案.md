# 210 · 数组 A 的索引字段 `[dwRoomImp+0xE360]` 定案 —— `0x6327ED` 构造点解析

> 卷次：210（房间类 · 数组 A 用途定案）
> 方法：解析 `0x6327ED` 构造点的 `ecx` 计算式
> 结论：**`ecx = [dwRoomImp+0xE360] × 0x238 + dwRoomImp + 0x7470`** —— 指向数组 A 内某元素。

---

## §0 关键代码

```asm
0x6327C5  mov eax, [esi + 0xE360]        ; ★★ 索引字段
0x6327CB  imul eax, eax, 0x238           ; × 元素大小
0x6327D1  lea ecx, [eax + esi + 0x7470]  ; ★★ 元素地址
0x6327E1  mov dword [esp+0x18], 3        ; type = 3
0x6327E9  mov dword [esp+0x14], 0xDC751C ; vtable = StartGame
0x6327F1  mov dword [esp+0x1C], ecx      ; ★ [this+8] = 元素地址
0x6327F5  call 0x62ABF0                  ; 发送
```

### 0.1 地址换算

```
元素地址 = idx × 0x238 + dwRoomImp + 0x7470

idx = 0  → dwRoomImp + 0x7470
idx = 1  → dwRoomImp + 0x76A8   ★ 数组 A 起点（193 卷算出）
idx = 48 → dwRoomImp + 0xDEF0
```

★★★ **`idx ≥ 1` 时落在数组 A `[0x76A8, 0xE360]` 内。**
**`idx = 0` 时是 `+0x7470`，恰好在单例 C `[0x7238, 0x7470]` 之后 0 字节处。**

★ 注意：`0x7470` = 单例 C 的**终点**（`0x7238 + 0x238 = 0x7470`）。

⇒ **数组 A 的"第 0 个元素"起点是 `+0x7470`**，即：
```
单例 C:  [0x7238, 0x7470]
数组 A:  [0x7470, 0xE360]   ← 起点修正！
```

★★★ **更正 193 卷**：数组 A 起点不是 `0x76A8`，是 **`0x7470`**！
193 卷算的 `0x76A8` 是 `idx=1` 的元素。

### 0.2 数组 A 的真实规格

```
数组 A: [0x7470, 0xE360]
  跨度 = 0xE360 - 0x7470 = 0x6EF0 = 28400 字节
  元素 = 0x238 = 568
  元素数 = 0x6EF0 / 0x238 = 28400 / 568 = 50
```

★ **50 个元素**（不是 49）！

★ 而 `0x637D01` 的循环是 49 次 —— 说明循环初始化 49 个，第 50 个（idx=0 对应 `0x7470`）是单例？

⇒ 需要重新核对。**但 `idx` 从 `[+0xE360]` 读，范围 0..49 都有可能。**

## §1 `[dwRoomImp+0xE360]` 是什么

| 项 | 值 |
|---|---|
| 地址 | `dwRoomImp + 0xE360` |
| 类型 | 32 位整数 |
| 语义 | **数组 A 的当前索引** |

★ 它与 `dwRoomImp + 0x3A0F8`（`0x637C48` 里 `esi=4` 的循环）、`+0x3A100` 等相邻。

⇒ **是 `dwRoomImp` 的一个计数器字段。**

## §3 对服务端的意义

★★★ **`0x6327ED` 是"从数组 A 取一个元素作为 StartGame 的 `[this+8]`"的路径。**

数组 A 是 **matchmaking 槽位数组**（每个槽是一个 MMI，568 字节）。

⇒ **客户端有多达 50 个 matchmaking 槽，`[+0xE360]` 指向当前使用的那个。**

★ 服务端要发 StartGame，**必须对应客户端正在用的那个槽** —— 这解释了为什么"服务端随便发"不行。

## §5 方法论

1. **★★★ 从 `imul reg, N` + `lea reg,[reg+base+disp]` 直接读出"数组索引 × 元素大小 + 基址"。**
2. **★★ 索引字段（`[base+0xE360]`）通常与数组在同一对象里，位置在数组之后。**
3. **★★★ 193 卷的 `0x76A8` 是"循环第一次写的元素"，不是"数组起点"。** 数组起点要按 `idx=0` 算。
