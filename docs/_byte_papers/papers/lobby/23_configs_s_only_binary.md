## 4. ★ 但它可以是"垃圾"

`configs_s.info.bak_dummy`（311 字节）：

```
54 BD F1 C2 C7 04 8C 32 27 CD 4B F5 3E 59 65 0B ...
```

**同样是随机字节，但只有 311 字节，且不是 25,126 的子串。**

**如果项目里有人把它替换成 311 字节的随机数据跑通过，
说明客户端不校验 `configs_s.info` 的内容 —— 甚至可以给垃圾。**

**这是"填充物"，不是"必要数据"。**

---

## 5. 推论

`configs_s.info` 很可能是：

- 某个"配置签名"或"防篡改校验块"
- 客户端只是收下来，不做严格校验
- 或者只在特定条件（在线）下才验证

**无论如何，它不是"卡住大厅"的关键。**
