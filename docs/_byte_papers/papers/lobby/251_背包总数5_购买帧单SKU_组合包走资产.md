## §1 ★★★★ 最大背包数 = 5

```asm
0x7D73E0  push ebp / mov ebp,esp
0x7D73E7  mov esi, [eax]              ; 返回对象
0x7D740A  mov dword ptr [esi + 0x10], 5   ; ★★ 常量 5
0x7D7411  mov dword ptr [esi + 0xc], 3    ; 返回类型 int
```

**⇒ 背包索引 0..4，即 1 号..5 号。249 卷的 `index 3 / 4` = 4 号 / 5 号背包，正好是最后两个。**

### 1.1 同族返回常量对照

| 函数 | impl | 返回 |
|---|---|---|
| `WL_GetMaxNumLoadouts` | `0x7D73E0` | **5** |
| `WL_GetUnlockedMPLoadoutNum` | `0x7D3E30` | **0x3C (60)**（★语义未定） |
| `WL_GetPick10LoadoutCount` | `0x7D3840` | `call 0x7DE610`（动态） |
| `AS_IsLoadoutUnlocked` | `0x5CC9A0` | bool **1**（常量） |

★ 四个都用同一套包装（`shr ecx,6 / test cl,1` 判写模式 → `mov [esi+0x10], <值>`），**形态一致、来源不同**。

### 2.2 `80/154`（1 条，58B）

同构，仅末段为 `08 01 00 00 00`（= 1）而 `93/131` 为 `08 00 00 00 00`。

★ **三条帧都只有**一个** SKU 字段（第 2 个 u32）。 ⇒ **不存在"一次购买多个 SKU"的帧形。**

★★ **⇒ 248 卷 Q1「组合包」的猜测需要收紧**：组合包**不是**"多 SKU 帧"，而是**单个 SKU**，

## §3 ★★★ 组合包走资产系统，不走商品

```asm
0x7D2130  ... 
0x7D2146  mov ecx, [eax + 0x10]
0x7D2149  mov ecx, [ecx + 0x10]        ; bundle 索引
0x7D214C  lea eax, [ebp - 0xfa8]
0x7D2152  call 0x80CD80                ; ★ 按索引查资产
0x7D2157  mov edx, [ebp - 0xfa8]
0x7D215E  lea eax, [ebp - 0xfa4]
0x7D2165  call 0x7D2280                ; 应用
```

`0x80CD80`（`(out, cx=index)`）：

```asm
0x80CD8F  cmp ecx, [0x7797FFC]         ; 计数 1
0x80CD8F  jae → 返回 0
0x80CD9D  movzx ecx, word [edx + ecx*2]  ; 二级索引（u16）
0x80CDAE  lea edx, [ecx*8]
0x80CDB5  sub edx, ecx                 ; ecx*7
0x80CDBD  lea esi, [ecx + edx*4]       ; ★ 步进 28 = 0x1C
```

★ **步进 `0x1C` = 28 = CoD 标准 XAsset 头大小**（与 155 卷「资产注册表 stride `0x1C`」一致）。

**⇒ `组合包` 在客户端是**资产（asset）**，通过两级索引表 `[0x7797FF8]` → `[0x7797FE8]` 解析。**
**这与"商品(SKU)"是两套东西。**

## §6 方法论

1. **★★★★★ 「帧结构」要用语料定，不要从代码猜。** 248 卷我猜"组合包可能带多个 SKU"，实际三条真实帧都只有**一个** SKU 字段。**猜测与样本冲突时，样本赢。**
2. **★★★★ 「常量返回值」是最好用的语义锚。** `WL_GetMaxNumLoadouts` 直接 `mov [ret+0x10], 5` —— **不需要任何推断就知道最大背包是 5**。
3. **★★★ 步进值能识别结构类型。** `0x1C` 一出现，就能判定那是 **XAsset 头**而不是普通结构 —— 这与 155 卷的资产注册表观察互相印证。
4. **★★ 同族函数形态相同不代表语义相同。** 四个"返回计数"的函数包装完全一致，但一个是常量 5、一个是常量 60、一个是动态调用、一个是 bool。**必须逐个读返回值来源。**
