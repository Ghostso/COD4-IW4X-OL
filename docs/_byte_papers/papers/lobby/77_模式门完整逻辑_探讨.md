## 四、最可能错的判断

**回顾 `lobby/51`：**

```
0x808261  cmp [0x849ba30], 3
0x808268  jne 0x80852c
```

**我当时理解为"不等于 3 就跳过整段"。**

**但 `0x80852c` 只是 `pop/ret` ——
那说明这个 `jne` 是**函数末尾的提前返回**，
而不是"跳过中间一段"。**

**⇒ 也就是说，`0x808240` 在 `[0x849ba30] != 3` 时**什么都不做**。**

**⇒ 这是对的。**

**⇒ 那 `[0x849ba30]` 必须由别处设为 3。**
