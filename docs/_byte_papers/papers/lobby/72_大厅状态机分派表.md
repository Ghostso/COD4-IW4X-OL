## 2. ★ 状态 8 的分支（`0x7ef3fe`）

```asm
0x7ef3fe  call 0x802cc0           ; 前置动作
0x7ef403  mov byte [0x82e158a], 0
0x7ef40a  mov byte [0x82e158b], 0
0x7ef411  mov dword [0x849ba34], 3   ; ★★★ 设为 3
0x7ef41b  ret
```

**⇒ 状态 8 执行完，把大厅状态设成 **3**。**

**⇒ 这是"进入大厅"的那一步。**

---

## 3. 状态 8 的进入条件

**表 2 的索引是 `ecx`，而 `ecx` 从哪来？**

**需要看 `0x7ef183` 附近的代码：**

```asm
jmp table @ 0x7ef183 (disp=0x7ef43c, index=ecx)
```

**⇒ 前面有 `mov ecx, [0x849ba34]` 或类似。**

**⇒ 索引就是当前大厅状态号。**

---

## 4. 状态机的完整流程（推定）

```
状态 0  → 0x7ef18a
状态 1  → 0x7ef1c8   （0x7f25b0() == 3 判断，见 lobby/53）
状态 2  → 0x7ef266
状态 3  → 0x7ef271
状态 4  → 0x7ef2ca
状态 5  → 0x7ef2d5
状态 6  → 0x7ef2f1
状态 7  → 0x7ef335   （cmp eax,4 / cmp eax,3 分支）
状态 8  → 0x7ef3fe   ★ → 设状态 3
状态 9  → 0x7ef39c
```

**注意：状态 8 执行后设置的是"状态 3"。**

**⇒ "状态 3"是内部工作态，"状态 8"是过渡态。**

**⇒ 8 → 3 是一个回调。**

## 5. ★ 与 `lobby/51` 的关系

**`lobby/51` 说 `[0x849ba30] == 3` 才初始化房间。**

**现在知道状态 3 由状态 8 设置。**

**⇒ 完整路径：**

```
某状态 → 状态 8 → 0x7ef3fe → [0x849ba34] = 3
                              ↓ 每帧同步
                          [0x849ba30] = 3
                              ↓
                          房间初始化
```

**⇒ 所以关键是"什么时候进入状态 8"。**

## 6. 状态 8 的触发

**从 `0x7ef335`（状态 7）看：**

```asm
0x7ef335  cmp eax, 4
0x7ef338  jne 0x7ef357
0x7ef33a  cmp dword [0x849ba28], 5
0x7ef341  jge 0x7ef266          ; >= 5 → 跳状态 2
0x7ef347  mov [0x849ba34], 9    ; 否则 → 状态 9

0x7ef357  cmp eax, 3
0x7ef35a  jne 0x7ef37e
0x7ef35c  call 0x803780         ; ★ 设置登录阶段 5
0x7ef361  call 0x622220
0x7ef366  test al, al
0x7ef368  je  0x7ef41b
0x7ef36e  mov [0x849ba34], 8    ; ★★★ 进入状态 8
```

**⇒ `eax == 3` 且 `0x622220()` 返回真，才进状态 8。**

**⇒ `0x803780` 就是 `lobby/53` 里那个"设置登录阶段 5"的函数。**
