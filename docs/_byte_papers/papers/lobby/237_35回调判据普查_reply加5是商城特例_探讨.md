## 一、235 卷的错误链条

235 卷我做了三步推导：

```
① 扫全库 cmp byte [reg+5],0  →  6 处
② 其中 0x4A7FBE 是商城，0x4B5610 是另一个大厅服务
③ ⇒ "reply+5 是大厅服务响应的通用判据族"
```

**第 ① 步是对的（机械扫描）。第 ② 步也是对的（两个都是大厅代码）。第 ③ 步错了。**

### 错在哪

我做了 `grep` 式的计数，但没有检查**这 6 处是否属于不同的函数**。

本卷重新分组：

| 地址 | 所属函数 | 性质 |
|---|---|---|
| `0x4A7FBE` | `0x4A7FB0` | 商城回调 |
| `0x4A820D` | `0x4A8080`（同 0x4A7FB0 所在模块） | **商城** |
| `0x4A83FC` | `0x4A8400`（同上） | **商城** |
| `0x4B5610` | `0x4B55E0` | 通道 135 服务 |
| `0x61B026` `0x61C562` `0x61CB3C` `0x684D93` `0xB4A1D1` | 无关模块 | 非大厅服务 |

★ **"6 处"里，3 处是同一个商城模块的复制，5 处与大厅服务无关。真正独立的大厅服务只有 2 个（商城 + 通道 135）。**

**6 这个数字给了我"它很常见"的错觉。**

## 二、237 卷真正发现了什么

按 236 卷的遍历顺序（128 个发送函数 → 35 个回调）扫下来：

```
判据形态分布：
  cmp byte [ebp + 0xc], 0     ← 约 20 个回调（主流）
  cmp byte [eax + 5], 0       ← 只有商城 3 处
  cmp byte [0x8xxxxxx], 0     ← 约 10 个回调（全局开关）
  cmp byte [edi], 0           ← 3 个回调（对象首字节）
```

**主流是 `[ebp+0xc]`（第二个参数），不是 `reply+5`。**

★ **235 卷的标题「reply+5 不是商城专有」是对的，但副标题「大厅通用判据族」是错的。正确说法是「reply+5 确实是商城专有，235 卷把它当通用是错的」。**

## 三、更严重的问题：231 卷的判据顺序我读反了

231 卷我写：

> `0x4A7FB0` 开头：`0x4A7FB4 cmp byte ptr [ebp + 0xc], 0` …… `0x4A7FBE cmp byte [eax+5], 0`

**我在 231 卷的论文里确实抄了 `0x4A7FB4` 那一条**（原文有），但**在结论里只说 `reply+5`**，把 `[ebp+0xc]` 当作"不过是个前置检查"。

实际上：

```asm
0x4A7FB4  cmp  byte ptr [ebp + 0xc], 0
0x4A7FB9  jne  0x4A7FE7      ; ★ 非 0 就跳到"有数据"分支
0x4A7FBB  mov  eax, [ebp + 8] ; ← 只有第一参数为 0 才看 reply
0x4A7FBE  cmp  byte [eax + 5], 0
```

**⇒ `reply+5` 只在 `[ebp+0xc] == 0` 时才被检查。**

**如果客户端的调用方传 `[ebp+0xc] != 0`，`reply+5` 根本不会被读。**

★★ **这意味着 231 卷的根因结论有一个未验证的前提**：我假定空 ACK 时 `[ebp+0xc] == 0`。**这个假定我没有验证过。**

如果实际是 `[ebp+0xc] != 0`，那空 ACK 走的是 `0x4A7FE7` 分支（有数据），`state` 不会变成 2 —— **231 卷的根因就错了。**

## 四、我必须诚实说明这一条

**231 卷的结论「回空页 ⇒ state=2 ⇒ 商城永空」有一个未验证前提：「空 ACK 时 `[ebp+0xc] == 0`」。**

两种可能：

| 情况 | 后果 |
|---|---|
| `[ebp+0xc] == 0` | 231 卷结论成立（空 ACK ⇒ 查 reply+5 ⇒ 失败） |
| `[ebp+0xc] != 0` | 空 ACK 走"有数据"分支 ⇒ **不会 state=2** ⇒ 231 卷结论不成立 |

**如何验证**：读 `0x7FA800`（漏斗）如何调用回调、第二个参数从哪来。

这是**下一册的第一优先**，且是纯静态可做的。

★ **我不打算把这条藏起来。** 231 卷我在论文里写了"根因找到"，实际上是"根因候选，有一个未验证前提"。

## 五、这一卷的方法论收获

| 收获 | 具体 |
|---|---|
| **计数 ≠ 分布** | "出现 6 次"必须先按函数分组，看是不是同一个模块的复制 |
| **判据是序列不是单点** | 一个回调里有多条 `cmp`，它们有**先后顺序**，只取一条会读反 |
| **主流靠统计，特例靠点查** | 要判断"什么是通用"，必须扫足够多样本做分布；235 卷只看了 2 个就下结论 |
| **"根因"要标前置条件** | 写根因时必须列出"在什么前提下成立"，否则后来者会当前提已验 |
