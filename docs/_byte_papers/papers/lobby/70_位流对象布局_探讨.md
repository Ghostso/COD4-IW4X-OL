## 一、这一轮补上了什么

**位流对象 `[+0x08]` 缓冲区、`[+0x14]` 位偏移、`[+0x21]` 启用标志。**

**字节化规则：`ceil((bitpos + nbits) / 8)`。**

**⇒ "位如何变成字节"完全清楚了。**

---

## 二、另一个意外

```asm
0xb77b13  cmp byte [ecx+0x21], 0
0xb77b17  je  0xb77b28        ; 未启用 → 静默返回
```

**⇒ 位流写入**可以被完全禁用**。**

**⇒ 这是一个调试/功能开关。**

**如果它被设为 0，所有 serialize 都不会真正写数据。**

**⇒ 但它大概率是 1（默认启用）。**

**不过这条值得记下来：
如果将来发现"推送发了但客户端没收到"，
先检查 `[+0x21]`。**

---

## 三、`writeBits` 的简化

```asm
push 0 / push 0x1f / push 0 / push eax
call 0xb77a70
```

**⇒ `writeBits(n)` 实际是 `writeBitsCore(n, 0, 31, 0)`。**

**⇒ 写 31 位宽的 n（高位补 0）。**

**⇒ 所以"3 位"其实也是写一个 31 位数的高 3 位？

不，`writeBitsCore(value, start, width, pad)` —— width=0x1f=31。**

**⇒ 这里 31 是"最大宽度"参数，不是实际写 31 位。**

**需要看 `0xb77a70` 的实现才能确定。**

**⇒ 这是最后一个待确认点。**
