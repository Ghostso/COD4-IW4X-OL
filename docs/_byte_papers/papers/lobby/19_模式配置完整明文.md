## 4. ★ Gametypes —— 模式定义

```
// ****TEAM DEATHMATCH****
gametype tdm
name MPUI_TEAM_DEATHMATCH
script war
teambased
rule scr_game_playerwaittime              20
rule scr_game_playerwaitcountfactor       0.4
```

字段：

| 字段 | 含义 |
|---|---|
| `gametype <id>` | 模式内部 ID |
| `name MPUI_*` | **UI 显示用的本地化键** |
| `script <name>` | **实际执行的 GSC 脚本名** |
| `teambased` | 是否分队 |
| `rule <dvar> <val>` | 本模式独有的规则覆盖 |

**`script man` = 模式逻辑的脚本入口。**

## 9. 对"完全自定义大厅"的意义

用户要求："可以随意修改大厅，包括新增模式删除模式添加按钮删除按钮，
甚至可以完全自定义整个页面。"

**`catinfo` + `gametype` 这套配置，正是"模式按钮"的数据源。**

- 加按钮 = 加 `catinfo`
- 删按钮 = 删 `catinfo`
- 改分组 = 改 `Group`
- 加模式 = 加 `gametype` + 对应脚本

**这条路不需要 AES 密钥**（如果服务端下发优先）。
