## 1. 状态查询函数 `0x7f25b0`（完整反汇编）

```asm
0x7f25b0  cmp byte ptr [0x849ba3d], 0
0x7f25b7  mov eax, 4                 ; 默认返回 4
0x7f25bc  jne 0x7f25db               ; 标志非 0 → 返回 4（失败）
0x7f25be  mov ecx, [0x84aba50]       ; ★ 登录阶段
0x7f25c4  cmp ecx, 5
0x7f25c7  ja  0x7f25db               ; > 5 → 返回 4
0x7f25c9  jmp [ecx*4 + 0x7f25dc]     ; ★ 跳转表
0x7f25d0  mov eax, 1 / ret           ; 返回 1（进行中）
0x7f25d6  mov eax, 3 / ret           ; 返回 3（完成）
0x7f25db  ret                        ; 返回 4（错误）
```

### 跳转表（`0x7f25dc`，6 项）

| `[0x84aba50]` | 跳转目标 | 返回值 | 含义 |
|---|---|---|---|
| 0 | `0x7f25db` | **4** | 未开始 |
| 1 | `0x7f25d0` | **1** | 进行中 |
| 2 | `0x7f25d0` | **1** | 进行中 |
| 3 | `0x7f25d0` | **1** | 进行中 |
| 4 | `0x7f25d0` | **1** | 进行中 |
| **5** | **`0x7f25d6`** | **3** | **★ 完成** |

**⇒ 只有 `[0x84aba50] == 5`，才返回 3。**

## 2. 实测

```
[0x84aba50] = 0     ⇒ 查询返回 4
[0x849ba3d] = 0     ⇒ 不触发失败分支
```

**⇒ `0x7f25b0()` 返回 4。**

**而状态机要求 `cmp esi, 3` → 不等 → 走 `0x7ef210` 分支。**

## 4. 完整判据

```
[0x8269774] != 0            （会话对象存在）
        ↓
0xb7a670() == 2             （★ 连接状态码 == 2）
        ↓
[0x84aba50] = 5             （登录阶段完成）
        ↓
0x7f25b0() 返回 3
        ↓
[0x849ba34] = 3             （大厅状态机）
        ↓
[0x849ba30] = 3             （镜像）
        ↓
0x808261 通过
        ↓
房间初始化 → 房间对象创建
```

**⇒ 六个条件，全部有地址。**

---

## 5. `0xb7a670` 是关键

**它返回 2 才代表"连接完成"。**

**`0xb7a670` 的地址段（`0xb7xxxx`）与**
**`memory: codol-dwroom-protocol-reversed` 里的位流读写器
（`0xB77B10` / `0xB777C0` / `0xB774E0`）相邻。**

**⇒ 它很可能是 Demonware 连接层的状态查询。**

## 7. 与项目已有记录的对齐

`memory: codol-iips-must-be-enabled` 说：

> 改 `enable_iips=1` 后完整进大厅（`5E8=1→3`）

**现在能解释那个 `1→3`：**

- `5E8` 可能就是 `[0x84aba50]` 的某个镜像
- `1→3` 是 `0x7f25b0()` 的返回值从 1 变成 3
- **而 3 的前提是 `[0x84aba50] == 5`**

**⇒ 那条记录的机制，本卷给出了完整代码路径。**
