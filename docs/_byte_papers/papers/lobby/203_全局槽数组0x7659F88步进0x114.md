# 203 · 发现第三个全局数组：`0x7659F88 + idx×0x114`（与 `0x77C290` 同源）

> 卷次：203（房间类 · 新发现的全局结构）
> 结论：`0x4F4570` / `0x4F4870` 操作 `0x7659F88 + idx×0x114`，与 `0x77C290` 的 `imul eax,eax,0x114` 同源。

## §0 三处代码指向同一个全局数组

### 0.1 `0x77C290`（退出清理）

```asm
0x77C296  mov eax, [0x7644694]        ; ★ idx
0x77C2AB  imul eax, eax, 0x114        ; ★ 步进 0x114
0x77C2B1  mov eax, [eax + 0x7659F88]  ; ★ 数组基址
0x77C2B7  mov edx, [eax]
0x77C2BB  mov eax, [edx + 0x24]       ; vtable[0x24]
0x77C2BE  call eax
```

### 0.2 `0x4F4570`（槽位枚举）

```asm
0x4F45AC  imul eax, eax, 0x114        ; ★ 同样步进
0x4F45B2  add eax, 0x7659F88          ; ★ 同样基址
0x4F45B7  cmp dword [eax], 0          ; 检查槽是否为空
0x4F45BC  inc ecx
0x4F45BD  add eax, 0x114              ; ★ 下一个槽
0x4F45C2  cmp ecx, edx                ; 循环
```

★★ **`0x4F4570` 是"遍历槽位找空位"的函数**，`edx` = 槽数上限（`0x30`=48 或 `0x40`=64 或 `0x31`=49）。

### 0.3 `0x4F4870`（销毁槽位）

```asm
0x4F4870  mov esi, [ebp+8]            ; idx
0x4F487D  imul eax, eax, 0x114
0x4F4884  mov edi, [eax + 0x7659F88]
0x4F4890  mov eax, [edx + 0x28]       ; vtable[0x28]
0x4F4895  call eax                     ; 析构
0x4F4899  mov eax, [edx]               ; vtable[0]
0x4F489B  push 1 / call eax            ; 释放
0x4F48A8  push 0x114 / push 0 / push esi / call 0x769840  ; ★ memset 0x114
```

| 项 | 值 |
|---|---|

| 元素大小 | **`0x114` = 276 字节** |

| 空槽判据 | `[eax] == 0`（元素首 dword = 0） |

### 1.1 元素结构（部分）

| 偏移 | 内容 |
|---|---|

## §2 这是什么

★ `0x7659F88` 是一个**全局对象槽位数组**，每槽 276 字节，最多 48/49/64 个。

候选：
- **连接槽**（每连接一个对象）
- **房间槽**（每房间一个）
- **玩家槽**

★★ 结合 `0x77C290`（退出清理）用它 ⇒ **很可能是"连接/会话槽"**。

## §6 方法论

1. **★★★ 全局数组的识别靠"`imul reg, N` + `add reg, BASE`"组合。** 两处不同函数用同一个 `0x114`+`0x7659F88`，就是同一个数组。
2. **★★ 空槽判据通常是"元素首 dword == 0"（vtable 指针为 0）。**
3. **★★ 槽数组的销毁 = `vtable[dtor] + vtable[release] + memset` 三连。**
4. **★★ 元素大小是强指纹：`0x114`(276) ≠ `0x238`(568)，是不同结构。**
