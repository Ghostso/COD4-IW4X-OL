# 大厅本体文件 · `.ifs` 容器逐字节逆向

> 对象：974 个 `.ifs`（23 GB），这是 CODOL 关服时的**全部游戏内容**
> 包括：大厅资源、模式定义（`common_gametype_*.ff`）、地图、武器、市场
> 证据：`tools/ifs_census.py`、`_byte_papers/ifs_census.tsv`、直接字节读

---

## 1. 为什么这是大厅逆向的入口

`IIPS/IIPSDownload/` 下 974 个 `.ifs` 就是全部内容。
`main/` 只有 `demo/` 和 `video/`，没有 `zone/`、没有散落的 `.ff`。

**想改大厅 UI、加按钮、加模式，内容只可能在这里。**

## 2. 文件头（0x00–0xAB，172 字节）

以 `ff_init_common_gametype_mp_V69.ifs`（34,819,339 字节）为例：

| 偏移 | 字节 | 类型 | 值 | 含义 |
|---|---|---|---|---|
| 0x00 | `6e 69 66 73` | char[4] | **`nifs`** | 魔数（"sfin" 反转 = "nifs"？实为小端写死） |
| 0x04 | `ac 00 00 00` | u32 | **172** | 头长度 |
| 0x08 | `00 00` | u16 | 0 | 保留 |
| 0x0a | `05 00` | u16 | **5** | **版本 / 常量**（974 个文件全部是 5） |
| 0x0c | u64 ×8 | 表 | 见下 | 8 个 u64 |

### 8 个 u64 表（0x0c–0x4b）

| 索引 | 偏移 | 值 | 推导 |
|---|---|---|---|
| [0] | 0x0c | `0x212C000` = 34,783,232 | |
| [1] | 0x14 | `0x2128BA9` = 34,769,833 | |
| [2] | 0x1c | `0x2128870` = 34,769,008 | |
| [3] | 0x24 | `0x212C000` = 34,783,232 | 与 [0] 相同 |
| [4] | 0x2c | `0x21344C0` = 34,817,216 | **L − [4] = 2123 = tail_len** ✓ |
| [5] | 0x34 | `0x329` = 809 | |
| [6] | 0x3c | `0x19a` = 410 | |
| [7] | 0x44 | `0x84c0` = 33,984 | |

**闭环验证**：`0x21344C0 + 2123 = 34,819,339 = 文件长度`。

所以 **[4] 是"尾部表起点"**，**[0]/[3] 是"数据区终点"**。

### 0x4c–0x53

| 偏移 | 值 | 含义 |
|---|---|---|
| 0x4c | u64 `2123` | **tail_len**（尾部表字节数） |
| 0x54 | u64 `0x0000400000004000` | 两组 u32：`0x4000`、`0x4000` —— **块大小 16384** |
| 0x5c–0x7b | 0 | |
| 0x7c–0xab | 6×u64 随机 | **签名 / 哈希**（`0xfd7f7828670a99ab` 等） |

## 3. 清单区（0xac 起，明文）

```
偏移 0xac:
"ff_init_common_gametype_mp.lst\r\n"
"client_shipRetail/chinese/common_gametype_mp.ff\r\n"
"client_shipRetail/chinese/localized_common_gametype_mp.ff\r\n"
偏移 0x13c: 16 字节（校验）
偏移 0x148: "IWff0100"      ← 载荷开始
```

### 关键结构

| 项 | 值 |
|---|---|
| 清单行数 | **3**（1 个 `.lst` + **2 个 `.ff`**） |
| 分隔符 | `\r\n` |
| 每个 `.ff` 后的 16 字节 | 校验 / IV |
| 载荷魔数 | **`IWff0100`** |

**一个 `.ifs` 可以装多个 `.ff`** —— 这是 `.ifs` 作为"分卷容器"的核心设计。

---

## 4. 载荷区（0x148 起）

### 4.1 `IWff0100` 头（24 字节）

| 偏移 | 字节 | 含义 |
|---|---|---|
| +0 | `49 57 66 66 30 31 30 30` | **`IWff0100`**（CoD 家族 `.ff` 魔数） |
| +8 | `cd 01 00 00` | 461（未知，可能是版本/段数） |
| +12 | `01 00 00 00` | **1**（很可能是"加密标志"） |
| +16 | `00 00 00 00` | 0 |
| +20 | `a4 a1 4f 9b` | 随机 |

### 4.2 载荷本体

从 +24 开始到 `L − tail_len`。

**熵 = 7.96**（接近 8.0 = 真随机）。

## 5. 全量普查结果（974 个文件）

`tools/ifs_census.py` 读每个文件的头部 + 中部采样：

| 分类 | 文件数 | 说明 |
|---|---|---|
| 魔数 = `nifs` | **974 / 974** | 全部同一种容器 |
| `u16@0x0a = 5` | **974 / 974** | 版本恒定 |
| 载荷熵 ≥ 7.5 | **871** | 看起来加密 |
| 载荷熵 2 – 7.5 | **47** | 部分明文 |
| 载荷熵 < 2 | **56** | **几乎全是明文** |
| 头 4KB 内含 `IWff` | **338** | 有直接内嵌 `.ff` |

### ★ 56 个低熵文件：`16417` 字节的固定形态

全部满足：**大小恰 16417 字节、熵 ≈ 0.028、无 `IWff`**。

打开其中一个（`lf_hi_init_coop_training_mp_cargoship_V11.4.ifs`）：

```
0x0000  nifs ...
0x00a8  (清单区开始)
0x00ac  "lf_hi_init_coop_training_mp_cargoship.lst\r\n"
        "hires/images/american_thread_color.iwi\r\n"
        "hires/images/blackhawk_body_normal.iwi\r\n"
        ... 共 69 行 ...
```

**这些是资源清单容器** —— 列出该分卷包含哪些 `.iwi`（图片）等资源，
但**不含资源本体**（本体在别的高熵 `.ifs` 里）。

## 6. 结论：`.ifs` 是一个三层结构

```
层 1  文件头 0x00–0xAB   （172 字节，明文，含 8 个 u64 指针）
层 2  清单区 0xAC–…      （明文，`.lst` + N 个 `.ff`/资源路径 + 每个后 16 字节校验）
层 3  载荷区 …–L-tail    （`IWff0100` 头 + 数据；大部分高熵）
层 4  尾部表 L-tail–L    （实测全 `01`，长度 = tail_len）
```
