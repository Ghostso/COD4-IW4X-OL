
★★ **负值路径把索引重置为 0，然后走第 0 槽。**

⇒ **`-1` = "无槽" → 回退到第 0 槽。**

## §1 与 211 卷的歧义解决

211 卷问："`0` 既是重置值又是第 0 槽，语义歧义"。

★★★ **本卷解答：`-1` 才是"无槽"，`0` 就是"第 0 槽"。**
重置时写 `0` 意味着"回到第 0 槽"，不是"无槽"。

| 值 | 语义 |
|---|---|
| `-1` | **无有效槽**（触发回退） |
| `0` | **第 0 槽**（有效） |
| `1..49` | 第 N 槽（有效） |

★ 5 处写 `-1` 是"标记无槽"，`0x62F975` 写 `0` 是"回退到第 0 槽"。

## §5 方法论

1. **★★★ `test reg,reg / js` 是"判负"的标准模式。** 配合"负值重置"能确定哨兵值。
2. **★★ 同一个寻址公式（`imul N` + `lea [reg+base+disp]`）出现三次以上 ⇒ 基址铁证。**
3. **★★ "重置值 = 0" 与 "合法值 = 0" 的歧义，靠"是否有另一个哨兵值（-1）"解决。**
