# 142 探讨 · 我的判据错了一个字节，结论就整个反了

> 配套：[142 · 类型号恒零穷举证明 + 43 个 dwRoomMessage RTTI 全表](142_类型号恒零穷举证明与43个dwRoomMessage_RTTI全表.md)
> 主题：**一个 ModRM 判据写错，让 141 卷报出了一个不存在的结论。这一卷把它纠正回来，并换了个证据源。**

---

## 一、错在哪

141 卷我扫"`0xB80D90` 里有没有 `[reg+4]` 的读"，用的是：

```python
if (m & 0xC7) == 0x40 and d[o+2] == 0x04:   # mod=01, rm=0
```

`0x40` 只覆盖了 `rm=0`（`[eax+disp8]`）。

而实际的指令是：
```
8b 4b 04      mov ecx, [ebx+4]
   ↑ ModRM = 0x4B
```
`0x4B & 0xC7 = 0x43`，**不等于 `0x40`** —— 判据直接漏掉了它。

**正确的判据应该是**：
```python
if (m >> 6) == 1 and (m & 7) != 4 and d[o+2] == 0x04:   # mod=01, 非 SIB
```

★★ **教训：`(m & 0xC7)` 只能覆盖 `rm=0`。要覆盖全部 8 个寄存器，必须用 `(m>>6)` 和 `(m&7)` 分开判。**

---

## 二、这个错误的后果

141 卷我据此写下："`0xB80D90` 全文无 `[reg+4]` 读"。

**然后我又用另一条路径（`as_show_135.py` 反汇编）看到了 `0xB80E37 mov ecx,[ebx+4]`**，两处矛盾。

我当时的选择是：**相信反汇编，把扫描器的结果当"扫错了"**。这个选择是对的。

但如果不幸选了另一边，结论就会变成"类型号根本不从 `[ebx+4]` 来"，整条链就断了。

★★★ **教训：两个工具给出矛盾结果时，先怀疑判据，再怀疑数据。**

---

## 三、修正后得到的结论反而更硬

修正判据重扫：

```
读侧：7 个 helper 全是 8b 4b 04（mov ecx,[ebx+4]），无一处 +1
写侧：全镜像只有 0xB82179 一处写 srpc+4（置 0）
```

**⇒ 类型号恒为 0，穷举证明。**

这比 141 的"倾向恒为 0"强了一个档次：**141 是"没找到自增"，142 是"证明了没有自增"**。

★ **"没找到"和"证明没有"是两种强度的结论**，141 卷把它们混为一谈了。

---

## 四、换证据源：RTTI 名字池

141 想追 srpc 的 RTTI 名，走的是标准路径：
```
vftable[-1] → COL → type_info → name
```
**全部撞在段2 空洞上**（`0xD599DC-4` 读为 0）。

142 换了一条路：**直接在整个文件里 regex 搜 `.?AVdwRoomMessage*`**。

**结果拿到 43 个类名。** 这些名字串本体在文件里是有的（虽然它们的 type_info 结构不在）。

★★★ **教训：结构体在空洞里，不代表字符串在空洞里。换证据源比继续挖同一条路划算。**

---

## 五、43 个名字带来的第三方对账

138 卷的 type→类 对应，是靠"构造器自证"（`mov dword [obj+4], k` 精确等于跳转表下标）建立的。

142 用 RTTI 名做**独立对账**：

- 138 表的 38 个类 → **36 个有 RTTI 铁证**
- 2 个"缺"是命名差异（`PrimaryWeaponCountChange` vs `PlayerPrimaryWeaponCountChange`）
- **另有 6 个 RTTI 类，138 表里完全没定位到**

★★ **这就是"两路独立互证"的价值：既验证了已有的 36 个，又发现了 6 个缺口。**

## 六、一个重要的澄清：两个"类型号"

这一卷让我意识到，我在 140/141 里一直混用"类型号"这个词：

| 名字 | 位置 | 值 | 用途 |
|---|---|---|---|
| **srpc 注册表类型号** | `srpc+4` | **恒 0** | 存进哈希表节点 `[node+4]` |
| **dwLobbyImp 消息泵类型号** | `[ebp-0x78]` | 4 字节名 FNV 查表 | 决定 `0xB83744` 下标 |

**这两个是完全不同的东西。**

★★★ **教训：同一个词在两个子系统里指不同的量时，必须分别命名。**
