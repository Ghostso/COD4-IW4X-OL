## 2. `80/70`（34 字节）

```
+000  10 00                 空字符串
+002  08 01 00 00 00        u32 = 1
+007  08 d0 07 00 00        u32 = 2000
+012  01 01                 bool = true
+014  08 00 00 00 00        u32 = 0
+019  08 00 00 00 00        u32 = 0
+024  10 "1625160" 00       字符串 "1625160"
+032  00                    终止
```

**`"1625160"` 是项目里出现过的数字串（`lobby/08` 记录过）。**

**⇒ 这是一个"查询商品"的请求：**
`(type=1, count=2000, flag=true, a=0, b=0, sku="1625160")`

## 3. `80/107`（22 字节）

```
+000  10 00                 空字符串
+002  08 01 00 00 00        u32 = 1
+007  08 d0 07 00 00        u32 = 2000
+012  10 "1625160" 00       字符串
+021  00                    终止
```

**⇒ 与 `80/70` 相同的前三项，但少了 bool 和两个 u32。**

**⇒ `80/70` 是 `80/107` 的超集（多了 3 个字段）。**

**两者查同一个 SKU `"1625160"。**

## 4. ★ `80/119`（23 字节，83 种不同值）

```
+000  10 00                 空字符串
+002  08 01 00 00 00        u32 = 1
+007  08 e8 03 00 00        u32 = 1000
+012  08 <u32>              ★ 变化字段
+017  08 00 00 00 00        u32 = 0
+022  00                    终止
```

**⇒ 唯一变化的是 `+0x0D` 处的 u32。**

**实测取值：**

| 值 | 出现 |
|---|---|
| `0x6c c0 27 76` | 多数 |
| `0x6c c0 35 bc` | 多数 |
| `0x6c c0 38 42` | 多数 |

**全部以 `0x6CC0` 开头！**

**⇒ 高 16 位固定为 `0x6CC0`，低 16 位变化。**

**`0x6CC0xxxx` 是十进制 1,822,000,000 量级 —— 像一个时间戳或递增 ID。**

## 5. `80/130`（6 字节，176 条）

```
08 0a 00 00 00     u32 = 10
00                 终止
```

**⇒ 一个纯参数请求：`(10)`。**

**`lobby_server.py` 注释："balance 80/130 currency=1 值=963849"。**

**⇒ 这是"查询币种 1 的余额"，参数 10 可能是币种ID或分页。**

---

## 6. `80/173` / `80/203`（各 6 字节）

```
10 00 06 bc 02 00    空串 + u16(700) + 终止     ← 80/173，88 条
10 00 06 20 4e 00    空串 + u16(20000) + 终止   ← 80/203，3 条
```

**⇒ `u16 = 700` / `20000` 两个不同的值。**

**可能是"商品分类 ID"。**

## 7. `80/174`（13 字节）

```
10 00              空字符串
08 01 00 00 00     u32 = 1
08 bc 02 00 00     u32 = 700
00                 终止
```

**⇒ 与 `80/173` 的 `u16=700` 呼应，但这里是 u32。**

**⇒ 同一个值 700，两种编码 —— 说明 `80/173` 和 `80/174` 查的是同一类东西。**

## 10. 常量汇总

| 常量 | 出现位置 | 值 |
|---|---|---|
| `2000` (`0x7D0`) | 80/70, 80/107 | u32 |
| `1000` (`0x3E8`) | 80/119 | u32 |
| `700` (`0x2BC`) | 80/173(u16), 80/174(u32) | |
| `20000` (`0x4E20`) | 80/203 | u16 |
| `10` | 80/130 | u32 |
| `"1625160"` | 80/70, 80/107 | 字符串 |
| `0x6CC0????` | 80/119 | u32 |

**`2000 / 1000` 是取整的十进制数 ⇒ 像"数量上限/步长"。**
**`700` 在两条报文里都是同一个值 ⇒ 同一实体。**
