# 连接单例：`[0x8269774]` 与它的 0x1618 字节

> 承接 `lobby/54`
> 把最后一个成员（`[esi+0x4F8]`）的宿主对象确定下来。

---

## 1. 获取函数 `0x803830`

```asm
0x803830  mov eax, [0x8269774]        ; ★ 全局连接单例
0x803835  test eax, eax
0x803837  jne 0x8038a7                ; 已存在 → 直接返回

0x803839  push 0x1618                 ; ★ 字节数 5656
0x80383e  call 0xb74220               ; operator new
0x80384a  mov ecx, eax
0x80384c  call 0xb82130               ; 构造
0x803851  mov [0x8269774], eax        ; ★ 存到全局
0x80385a  push 0xe39b6e8
0x803861  call 0xb7a400               ; 初始化
0x803866  push 4
...
```

**⇒ 连接对象大小 **0x1618 = 5656 字节**。**

**⇒ 全局指针在 `0x8269774`。**

---

## 2. `[esi+0x4F8]` 的绝对地址

如果 `esi = [0x8269774]`，那：

```
[esi+0x4F4] = 连接子对象
[esi+0x4F8] = 认证标志（byte）
```

**注意：`[esi+0x4F4]` 存的是一个**指针**（`mov ecx, [esi+0x4F4]` 然后 `test`），
而 `[esi+0x4F8]` 是直接比较字节。**

**⇒ 两个字段类型不同：**

| 偏移 | 类型 | 含义 |
|---|---|---|
| `+0x4F4` | pointer | 连接子对象 |
| `+0x4F8` | byte | 认证/就绪标志 |

---

## 3. 调用链（`0x4700ab`）

```asm
0x47008e  cmp ecx, 4                ; 某个模式值
0x470091  je  0x47009c
0x470093  cmp ecx, 6
0x470096  jne 0x4701fa
0x47009c  call 0x803830             ; ★ 取连接单例
0x4700a1  mov esi, eax
0x4700a3  test esi, esi
0x4700a5  je  0x4701f4              ; 无单例 → 退出
0x4700a7  mov ecx, esi
0x470109  call 0xb7a670             ; ★ 查询连接状态
```

**⇒ 只有 `[0xe59d20]` ∈ {4, 6} 时，才会查连接状态。**

**这又是一个模式闸门。**

---

## 6. 剩余的两个未知

### 未知 1：`[esi+0x4F8]` 谁写

**它决定"认证标志"。需在连接对象内部搜索对该偏移的写入。**

**但它是相对偏移（`+0x4F8`），需要先知道所有 `[conn+0x4F8]` 的访问点。**

### 未知 2：`[0xe59d20]` 是什么

**它的值必须是 4 或 6，才会去查连接状态。**

**可能是"当前场景/模式"（例如 4=大厅，6=游戏中）。**
