## §5 方法论

1. **★★★ "无 vtable 引用 + 无 call" 的函数，先查它是不是 thunk/死代码，再查间接调用。**
2. **★★★ 构造函数和析构函数必须成对验证。** MMI ctor 不碰 `+0x24`/`+0xD8` ⇒ 那个析构不可能是 MMI 的。
3. **★★ 元素大小（132/4）是强指纹，可用于反查类身份。**
4. **★★ 一个类"有析构没构造"或"有构造没析构" ⇒ 我的类归属判断一定有错。**
