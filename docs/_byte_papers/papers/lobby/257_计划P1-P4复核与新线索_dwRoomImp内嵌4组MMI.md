## §2 新线索：`dwRoomImp+0x20` 也是一个 MMI

构造函数 `0x62C000`（255 卷）：
```asm
0x62C020  lea ecx,[ebx+0x20]
0x62C02C  call 0x806B50          ; ★ [this+0x20] 构造一个 MMI（0x806B50 = MMI ctor，198 卷）
...
0x62C099  mov [ebp+0xC],0x31
0x62C0A4  call 0x806B50          ; [this+0x340] 起，50 个（步进 0x238）
0x62C0C2  call 0x806B50          ; [this+0x7238] 单个
0x62C0D8  call 0x806B50          ; [this+0x7470] 起，50 个
```

⇒ dwRoomImp 内至少 4 组 MMI：`+0x20`（1）/ `+0x340`（50）/ `+0x7238`（1）/ `+0x7470`（50）。
★ 191–216 卷只登记了 `+0x7238` / `+0x7470`。**`+0x20` 与 `+0x340` 是本卷新增**。

### 2.1 与 P1 的关系（待定，勿过度宣称）

- StartGame 成功分支（254 卷）用 `0x6327D1 lea ecx,[eax+esi+0x7470]` ⇒ 它操作的是 **`+0x7470` 数组**的 MMI 元素。
  ⇒ **P1 的 `MMI+0x18` 缓冲落在 `+0x7470` 数组元素内**（元素基址 `+0x7470+idx*0x238`），**不是 `+0x20`**。
- 故 `+0x20` MMI 是**另一用途**（可能对应"本地单机/训练"或"当前房间"快照），**归属待定**。
