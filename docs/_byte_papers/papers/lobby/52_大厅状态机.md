# ★★★★★ 大厅状态机：`[0x849ba34]` 的 10 个状态

> **这是大厅的核心状态机，房间初始化只是它的一个下游**
> 证据：`client_runtime.bin`，写入点全量扫描

---

## 1. 状态变量

```
[0x849ba34]   主状态（写入者）
[0x849ba30]   镜像（每帧同步）
```

**同步代码（`0x7ef0d6`–`0x7ef0f6`）：**

```asm
0x7ef0d6  mov eax, [0x849ba34]      ; 读源
0x7ef0db  cmp eax, [0x849ba30]      ; 与镜像比
0x7ef0e2  setne bl                  ; 是否变化
0x7ef0f6  mov [0x849ba30], eax      ; ★ 同步
0x7ef0fb  jne 0x7ef12a              ; 变化则走状态切换
```

**⇒ 每帧把 `0x849ba34` 拷到 `0x849ba30`。**

**⇒ 状态机是 `0x849ba34`。**

## 3. 状态 1 的进入条件（`0x7ef1b3` 附近）

```asm
0x7ef1a1  mov eax, [0x849b874]     ; 某个对象
0x7ef1a6  test eax, eax
0x7ef1a8  je  0x7ef41b             ; 为空 → 退出
0x7ef1ae  cmp dword [eax+0xc], 0
0x7ef1b2  je  0x7ef41b             ; 字段为 0 → 退出
0x7ef1b3  call 0x7eebc0
0x7ef1b8  mov [0x849ba34], 1       ; ★ 进入状态 1
```

**⇒ 状态 1 的前提是 `[0x849b874]` 存在且 `[+0xC] != 0`。**

---

## 4. 状态 3 的进入条件（`0x7ef411` 附近）

```asm
0x7ef3fe  call 0x802cc0
0x7ef403  mov byte [0x82e158a], 0
0x7ef40a  mov byte [0x82e158b], 0
0x7ef411  mov [0x849ba34], 3       ; ★ 进入状态 3
```

**⇒ 状态 3 只在 `0x7ef3fe` 这条路径上被设置，
前面无条件调用 `0x802cc0` 并清零两个标志。**

**⇒ 这个路径来自状态 2 的分支。**

## 5. 状态 2 → 3 的关键判断（`0x7ef1c8` 起）

```asm
0x7ef1c8  call 0x7f26c0
0x7ef1cd  call 0x7f25b0            ; ★ 返回某个状态码
0x7ef1d2  mov esi, eax
0x7ef1d4  call 0x8014a0
0x7ef1d9  call 0x7eebc0
0x7ef1de  cmp esi, 3               ; ★★★ 状态码 == 3？
0x7ef1e1  jne 0x7ef210             ; 不是 → 另一分支
0x7ef1e3  call 0x803780            ; 是 → 继续
0x7ef1e8  call 0x4a3ce0
```

**⇒ `0x7f25b0()` 的返回值必须 == 3。**

**这是从"连接"到"进大厅"的关键判据。**

---

## 6. `0x7f25b0` 是什么

**在 `lobby/40` 里出现过：**

```asm
0x4f8adb  call 0x7f25b0
0x4f8ae0  cmp eax, 1
0x4f8ae3  je  0x4f8ad1        ; == 1 则循环
```

**⇒ 它返回一个"连接状态码"，1 = 未完成，3 = 完成。**

**这与 `memory: codol-iips-must-be-enabled` 里的 `5E8=1→3`
完全一致！**

---

## 7. 完整状态机模型

```
[0x849b874] 存在且 [+0xC] != 0
        ↓
   [0x849ba34] = 1        （开始）
        ↓
   0x7f25b0() == 3 ?
        ↓ 是
   [0x849ba34] = 3        （★ 已进大厅）
        ↓
   [0x849ba30] = 3（镜像）
        ↓
   0x808261 通过
        ↓
   房间初始化执行
```

**⇒ 房间能不能用，取决于 `0x7f25b0()` 是否返回 3。**


**⇒ 状态机停在 0（或未到 1），从未进到 3。**
