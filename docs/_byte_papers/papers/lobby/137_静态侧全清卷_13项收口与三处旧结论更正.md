## §6 B12 + B13 · `0x13` room 族头部收口 ✅（本卷全量复核，分母 195/112）

抽取：`11/4` 的 `0x13` blob 剥外层 `[08][u32 len]` ⇒ 内层 **261** 条 = room(`0x02`) **195** + ready(`0x18`) **66**。

**头部 8 项不变量（195/195，无一例外）**：
`byte2=byte3=byte4=byte7=byte8=0`、`F1%1024==0`、`F2%2048==0`、`byte9%8==0`、`F1 == u16@[5:7]*256`。

结构 = `[02][V][00 00][u32 F1][u16 F2][数据体]`，其中
**`F1 = K<<10`**（`K = F1>>10`）、**`F2 = M<<11`**（`M = F2>>11`）。

### B13 ✅ —— "×4" 不是量纲
**`u16@[5:7] == 4·(F1>>10)`（195/195，恒等式）** ⇒ 所谓"×4"就是 `F1=K<<10` 被读**中间 16 位**后的投影。
- 对 V=02：**`K == len-10 == 数据体字节数`（112/112）**，故 `u16@[5:7] = 4×数据体字节数`。
- 已排除：`= 位长`（应 ×8，0/112）、`= u32 元素个数`（应 B/4，0/112）、`= float 个数`（0/112）、`= 数组容量`（无候选）。
- ⇒ **"×4 的单位仍不定"这个提法本身要撤回**：它是**编码位偏移的投影**，不存在独立单位。

### B12 —— 头部闭合，V 语义仍开放

## §16 方法论（本卷新增）

1. ★★★ **用"两个独立方法算同一件事"发现错位**：131 错位是靠"同记录配对"与"vtable 直读"两法给出**同一结论**才敢定的；**一法永远可能错位，两法不会同时错同一个位**。
2. ★★ **"最大公约数式"的字节统计**（`0x693DD0` 间隙直方图 803/830=12）比"挑几个样本看"硬得多；**一个直方图否掉了一卷的步进结论**。
3. ★★ **改一个错误的名字，会连带推翻一条结论**：131 的错位把 `AS_UILog` 说成 `AS_SetRecommendedSetting`，于是 135 才会去"更正 130"——**错位不是排版问题，它会生出一条错误的更正**。
4. ★ **"没找到"要穷举成"这里没有"**：§9 的字段名、§13 的页号、§5 的消息号业务含义——三处都做了**全量普查 + 记下命中数**，才敢写成"边界"。
5. ★ **交叉核对旧卷的每一步**：本卷 13 项里有 3 项的直接产出是"旧卷错了"（131/132/136）⇒ **"上一卷的结论"必须先过一遍本卷的判据再引用**。
6. ★ **替身证据要降到"推断级"**：§6 的子记录模型、§12 的 channel 候选——都由**关联**而非**因果**得出，全部标注「推断」。
