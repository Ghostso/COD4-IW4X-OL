## 2. 关键发现

### 2.1 `StartGame` / `StartGameFailed` 是一对

**⇒ 开局是一个有明确成功/失败分支的请求-响应。**

**客户端发请求 → 服务端回其中之一。**

### 2.2 `StartCountingDown` 在 `Ready` 之后

**顺序推测：**

```
Ready（所有人准备）
  ↓
StartCountingDown（倒计时开始）
  ↓
StartGame（开局）
```

### 2.3 `Manifold` 是批量容器

**⇒ 服务端可以把多个消息打包成一条推送。**

**这解释了 `11/4` 里为什么有"多组"结构（`02 04` / `02 06` / `02 08`）。**
