# 连接状态查询 `0xb7a670`：最后一个未知环节

> 承接 `lobby/53`

---

## 1. 完整反汇编（12 条）

```asm
0xb7a670  push esi
0xb7a671  mov esi, ecx                    ; this
0xb7a673  mov ecx, [esi+0x4F4]            ; ★ 连接对象
0xb7a679  test ecx, ecx
0xb7a67b  jne 0xb7a681
0xb7a67d  xor eax, eax / ret              ; 无连接 → 返回 0

0xb7a681  call 0xba0780                   ; ★ 查询底层状态
0xb7a686  cmp byte ptr [esi+0x4F8], 0     ; ★ 标志位
0xb7a68d  jne 0xb7a699                    ; 标志非 0 → 返回原值
0xb7a68f  cmp eax, 2                      ; 状态 == 2 ?
0xb7a692  jne 0xb7a699                    ; 不是 → 返回原值
0xb7a694  mov eax, 1                      ; ★ 是 → 改成 1
0xb7a699  pop esi / ret
```

---

## 2. 返回值逻辑

| 条件 | 返回 |
|---|---|
| `[esi+0x4F4] == 0`（无连接） | **0** |
| `0xba0780()` 返回 X，且 `[esi+0x4F8] != 0` | **X** |
| `0xba0780()` 返回 X，且 `[esi+0x4F8] == 0` 且 X != 2 | **X** |
| **`0xba0780()` 返回 2，且 `[esi+0x4F8] == 0`** | **1** |

**⇒ 注意：这个函数在"底层返回 2"时会**改成 1**。**

**⇒ 返回 2 的条件是：`0xba0780()` 返回 2 **且** `[esi+0x4F8] != 0`。**

---

## 3. 关键推论

**`0x8037d6` 要求 `esi == 2` 才设置阶段 5。**

**而 `esi` 来自这个函数。**

**⇒ 要让阶段 5，必须：**

1. `[esi+0x4F4] != 0`（连接对象存在）
2. `0xba0780() == 2`（底层状态）
3. **`[esi+0x4F8] != 0`**（★ 这个标志必须非 0）

**第 3 条是关键 —— 如果它是 0，返回值会被改成 1，永远进不了阶段 5。**

---

## 4. `[esi+0x4F8]` 是什么

**紧跟在连接对象 `[esi+0x4F4]` 后面 4 字节。**

**两个字段相邻 ⇒ 同一个结构体的两个成员。**

**名字推测：`connected` / `authenticated` / `ready`。**

**⇒ 这个标志决定了"是否已认证"。**
