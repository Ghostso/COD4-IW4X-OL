## 二、两个"未知"的真相

### 未知 1：「8 位字段标签是什么」

67 卷说：「`Manifold` 写死 `8`，`StartGame` 用 `0x13` ⇒ 是字段类型码，不同消息不同。」

**实测 `0xB77B10`：**

```asm
cmp byte [ecx+0x21], 0
je  ret                  ; 标志为 0 → 什么都不写
...
push 0                   ; 值 = 0
call 0xB77A70
```

**⇒ 那个 `WriteBits(8)` 不是写字段标签，是「强制 8 位零填充」，且正常路径下连 0 都不写。**

**⇒ `0x13` 是另一回事：它是 type=19=P2PInfo 的类型号，不是字段码。**
**67 卷把两条指令混成了"同一个字段"** —— 它们根本不在同一个函数里。

### 未知 2：「位流容器格式」

**定案：**
```
[3位] type&7  +  [8位] type  +  [8位] 0x00  +  [32位] count
每条: [1位] 存在  +  [1位] 值
```

**位数自己加：3+8+8+32 = 51 位 = 7 字节。**

**⇒ 而 67 卷早就在别处观察到「7 字节头」。两者对上 —— 反向验证了结构。**
