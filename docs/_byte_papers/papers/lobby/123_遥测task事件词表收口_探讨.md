# 123 探讨 · "没有语义"是误判：遥测在自报家门

> 配套：[123 · 遥测 task（`71/*`）事件词表收口](123_遥测task事件词表收口.md)
> 性质：方法论复盘。**主题：把"无语义"重新定义。**

---

## 一、清单里那句"只有结构、没有业务语义"

`INDEX §七 #2` 写着：「~15 个 task 只有结构、没有业务语义」，列了一串：`71/2`、`71/9`、`71/10`、`71/11`、`71/13`、`71/20`… 全是 `71/*`。

**我一开始也认了这句话。** 遥测嘛，一堆字节，看不出什么意思，就归到"无语义"。

**这轮一做普查，发现这句话是错的。** 不是"没有语义"，是"语义我没去看"。

## 二、`71/3` 的 payload 里明明白白写着事件名

把 `71/3` 的 payload 当 ASCII 看：

```
ClientLoadout|${TIMESTAMP_OFFSET(-4)}|16701785630074219790|${CODOID(...)}|70|B01|...
ClientLogin|...
CreateRoom|...
ChannelSubscriptionFail|...
```

**每一条事件都自报家门**：`事件名|${时间表达式}|值...`。

**"没有语义"这个判断，本质是"我没把字节当文本读"。** 我把 `71/*` 当成"二进制遥测块"，而它其实是**明文的、管道分隔的事件流**。

★ **这是 `0x13` 教训的又一例**：`09` 卷说过"`0x13` 不保证是二进制，先试 latin1"。这里 `71/*` 同理——**先当文本看一眼，再判断是不是二进制**。

## 三、顺手纠正了一个旧说法

`71/3` 里有 `CreateRoom`（×25）。

记忆 `pve-startgame-blocker-who-owns-start` 里写着："71/3 的 CreateRoom 是 TLog 不是开局"。**这轮找到了直接证据**——`CreateRoom` 就是 `71/3` 事件流里的一个**遥测事件名**，跟真正的建房命令 `11/13` 完全无关。

**⇒ 看到 `71/3` 里有 `CreateRoom` 就以为"客户端在建房"，是会被字面骗的。** 事件名里的动词 ≠ 实际动作。它只是打点。

## 四、`71/7` 把网络上下文全打出来了

`71/7` 的 `ClientDisconnect` 样本，一条里就有：

```
7554953631564092900        会话 id
16701785630074219790      账号 id + ${CODOID}
101.24.255.88:8382        公网 IP:端口
127.0.0.1:28960           本地端点
D4-93-90-18-55-10         MAC
1649370                   build
EXE_DISCONNECTED / CA_ACTIVE
```

★★ **遥测把"客户端当时看到的所有网络信息"都打了。** 这比我们专门去逆协议拿到的还全——**遥测是免费的信息金矿**。

**"无语义的遥测"反而是信息最全的 task。** 这是本卷最大的反差。

## 五、"无语义"其实是三种不同的东西

普查后我把它拆成三类：

- **A 遥测**：`71/3`、`71/7`… —— 语义在明文里（本卷给了词表）。**不是黑箱**。
- **B 固定常量**：`3/46`、`6/5`、`9/5`… `distinct=1`，全语料逐字节相同。**字节层已闭合**，"业务语义"归 service/task 层（`114` 卷）。**不是字节黑箱**。
- **C 仍需真 RE**：`71/15`（二进制，162 distinct）、`68/3`/`21/1` 的 `wfUD3"` 段（疑似密文）。**这才是真黑箱。**

★★ **一句话：§七 #2 的"~15 个"里，绝大多数根本不是黑箱，是被贴错标签的。** 真正要啃的只剩 `71/15` 和几个 `wfUD3"` 段。

## 六、诚实的部分

- `71/15`（162 distinct，二进制）**没解**。我只确认"它不是明文"。
- `wfUD3"` 段我只看到乱码，**没确认是加密还是压缩**（下一步才知道）。
- `71/3` 里那些"武器/情报名"事件（`WEAPON_INTEL_PACK` 等）各有 1 次，**没逐个追问为什么打这些点**。

**我没有为了"§七 #2 全收口"把 `71/15` 也说成已解。** 它确实是黑箱，就留着。

## 七、方法论（可迁移）

1. **"无语义"先怀疑是不是"没当文本读"。** 遥测常是明文管道分隔流，不是二进制。
2. **事件名里的动词 ≠ 动作。** `CreateRoom` 是打点，不是建房；别被字面骗。
3. **遥测是免费信息金矿。** 它自报会话 id、公网 IP、MAC、build、断开原因。
4. **"无黑箱"和"有黑箱"要按证据分，不按标签分。** §七 #2 的"~15 个"拆开后绝大部分不是黑箱。
