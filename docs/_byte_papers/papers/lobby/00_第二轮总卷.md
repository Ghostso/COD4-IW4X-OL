## 四、框架层：加密链完全逆向

### 4.1 `.ifs` 容器（完全解出）

| 偏移 | 内容 |
|---|---|
| 0x00 | `nifs` |
| 0x04 | u32 = 172（头长） |
| 0x0a | u16 = 5（版本） |
| 0x0c | 8×u64 指针表 |
| 0x4c | u64 `tail_len` |
| 0xac | 明文清单（`\r\n` 分隔） |
| … | `IWff0100` + 载荷 |
| L-tail | 尾部表（全 `01`） |

**验证：`tbl[4] + tail_len == 文件长度`，974/974 成立。**

### 4.2 `.ff` 加密（七条判据确认 AES）

| 判据 | 结果 |
|---|---|
| 熵 | 7.9998 |
| 0x00 / 0xFF | 0.39% / 0.40%（=1/256） |
| 16 字节块重复 | 0 / 262,143 |
| 16 列分布 | 全部 0.44–0.50% |
| 跨块相关 | ≈0.39% |
| zlib 解压 | 失败 |
| bzip2 解压 | 失败 |

### 4.3 加密链（完整）

```
RSA 2048 私钥（0xdac4b0，1187 字节 DER，已提取）
   ↓ rsa_decrypt_key_ex（0xbc8850，PKCS#1 v1.5，SHA-256）
密钥材料（≤40 字节）
   ↓
AES-128 密钥 16 字节 → 全局 0x1c51734
   ↓ 每 8192 字节
AES 块解密（0x4834f0 → 0xbc5f60 → 0xbc8840）
   ↓
zlib inflate（0x791eb0 = inflateInit2）
   ↓
.ff 内容
```

### 4.4 RSA 私钥（已保存）

`_byte_papers/rsa_private_key.json`

```
n : 2048 位
e : 65537
d : 2045 位
p, q : 各 1024 位
```

**数学验证通过：`p*q == n`，`e*d ≡ 1 (mod φ(n))`。**
