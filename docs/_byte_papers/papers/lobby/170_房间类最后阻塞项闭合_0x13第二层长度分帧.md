## 四、★ 结论：`0x13` blob 的完整分帧

```
[tag 0x13]
  [1 字节 sub]           ← 普通 or 0x16
  if sub == 0x16:
      [8 位 len1]
      [8 位 len2]
      [8 位 len3]
      分配 len3 缓冲 / 分配 len2 缓冲
      （三段依次填充）
  else:
      [普通读取路径]
```

**⇒ 「`V=04/06/08` 的第二层」= `sub=0x16` 的三段长度分帧结构。**

**⇒ `68 ab 5b ab 63 ab 03` 前缀的解读：**

| 字节 | 含义 |
|---|---|
| `68` | **= 0x68**，`sub` 前后的分隔/长度（0x68=104） |
| `ab 5b` | u16 = `0xAB5B` = 43867 |
| `ab 63` | u16 = `0xAB63` = 43875（差 8 —— 与"两段长度"吻合） |
| `03` | 段数或标志 |

**⇒ 前缀不是魔数，是「三段长度」本身。119 卷把它当"固定前缀"是因为**样本里这三段长度恰好稳定**。**

## 六、方法论

1. **★★★ 「没有样本」→「谁读它」。** `V=04/06/08` 悬了 51 卷（119→170），本卷从 `0x6371F0` 往下找 `0xB76AF0`，20 分钟定案。
