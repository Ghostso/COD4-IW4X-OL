# 第 5 卷 · 有符号整型标签 `0x07`

> 覆盖：`0x07` 标签及其 4 字节载荷（**有符号**）
> 证据：`_byte_papers/evidence/ev_value_stats.txt`（tag 07 段）
> 复跑：`tools/lobby_value_stats.py`

---

## 1. 结论

```
0x07 <4 字节小端 有符号 int32>
```

在 12634 个实例中，**407 个是负数**。

这是 `0x07` 与 `0x08` 唯一的、也是最关键的差别：
两者都是 4 字节，但只有 `0x07` 会出现负值。

## 3. 关键对照：`-1` 与 `0xFFFFFFFF`

`-1` 在 int32 下的位模式是 `FF FF FF FF`，
在 uint32 下是 `4294967295`。

语料里有 117 个 `0x07` 实例其载荷是 `FF FF FF FF`。

**如果 `0x07` 是无符号的**，这个值应被读作 4294967295 ——
一个几乎不可能在业务里出现的数。
读作 `-1` 则是标准的"无效 / 未设置"哨兵值。

这是第二条独立证据：**只有 `0x07` 里出现 `-1`，
而 `0x08` 的 129 个不同值里没有任何一个等于 4294967295。**

---

## 4. 报文逐字节（`21/5` 的完整结构）

`21/5` 是 findSessions 的应答体，语料里 159 条、6 种变体。
最短的 35 字节：

```
偏移  字节                          解释
00    08 01 00 00 00                u32 = 1
05    08 00 00 00 00                u32 = 0
0a    08 0a 00 00 00                u32 = 10
0f    07 ab ad 92 d6                i32 = -695030357
14    6b 08 04 00 00 00 ...        数组（第 11 卷）
```

第 15 字节开始的 `07 ab ad 92 d6`：
小端读作 `0xd692adab` = `-695030357`。

**这个值出现在每一个 21/5 样本里，位置完全相同。**

从数值上看它是"看似随机"的 32 位值 —— 很像一个 hash 或
security key 的半段。但在 `0x07` 标签下它是负数，
这本身不矛盾：hash 值在协议里常被当作有符号整数处理。

---

## 5. `0x07` vs `0x08` 辨析表

| 项 | `0x07` | `0x08` |
|---|---|---|
| 宽度 | 4 | 4 |
| 负值 | **有（407 例）** | 无 |
| 最大值 | 253009291 | 2082033314 |
| 值域特征 | 会出现 -1、-1924013160 | 只有非负 |
| 主要出现位置 | 21/1、21/5、21/12 | 全面（55 个 task 里 40+ 个） |

**两者不能互换。** 服务端构造代码里已经有一条实测教训：
matchmaking 的 query-criterion 字段是 SIGNED，写成 U32 会被客户端
逐值类型检查拒绝（`codol_crypto.py:260-261` 的注释）。

本卷的语料证据与这条教训完全一致：
客户端在 `21` 族里用的是 `0x07`，即 signed。

---

## 6. 出现位置的业务线索

`21/1`（269 字节）里，`0x07` 的值序列包含：

```
-1, -695030357, -1924013160, 30060, 30059, 30061, 10001, 10028, ...
```

`21/5` 里 `-695030357` 恒在。

这个值在不同会话间是否恒定？
语料里 21/5 的 159 条全部是 `-695030357` —— **跨 83 个 run 恒定**。

这说明它不是每会话随机的，而是**某个稳定标识**（可能是 session 类型 hash 或固定 security key）。

**语义归属留待第 13 卷。**

## 7. 字节覆盖

| 字节 | 语义 | 证据强度 |
|---|---|---|
| `0x07` | int32 标签 | 强 |
| 载荷 4 字节小端 | 有符号 | **强（407 例负值 + `-1` 哨兵）** |
| 恒定值 -695030357 | 跨 run 稳定 | 强（159/159） |

**盲区**：

1. 值 253009291 出现 37 次，来源分散，语义未解。
2. `21/12` 与 `21/1` 的关系（超集/子集）未完全理清 ——
   两者负值序列高度重合但长度不同。
3. `0x07` 是否在非 21 族出现过？—— 有，但占比很小（详见证据文件）。
