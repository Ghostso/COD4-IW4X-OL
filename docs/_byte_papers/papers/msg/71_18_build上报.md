## 为什么这 11 个字节特别重要

`1649370` = **本项目的目标 build 号**（AGENTS.md 首行）。

`0x00192ADA` = 1649370。

客户端在这个字段里**自报版本**。

## ★ 字节序的直接证据

`1649370` 的十六进制是 `0x00192ADA`。

**小端存储**：`da 2a 19 00` ← **实测就是这四个字节**

**大端存储**：`00 19 2a da`

这是本卷集合里**唯一一处字节序可以直接读出、不依赖同族推定**的地方。

第 4 卷（`0x06` u16）的字节序只能靠"同族都是小端"推定。
现在有了 `71/18` 这个锚点，那条推定从"惯例"升级为"有直接旁证"。
