## 2. 复制环节的偏移保持性（关键且已闭合）

`0x637950` 的复制是**整块 memcpy，不做字段重排**：

```
00637983  imul ecx, ecx, 0x238          ; ecx = k * 0x238
00637989  lea  edi, [ecx + ebx + 0x7470] ; dst = mk + 0x7470 + k*0x238
00637990  mov  ecx, 0x8E                 ; 0x8E dwords = 0x238 字节
00637995  mov  esi, eax                  ; src = 源记录基址
00637997  rep  movsd                     ; ★ 逐字节等价复制，无变换
```

**⇒ 结论（CONFIRMED）：源记录内的偏移 `X` 与槽内偏移 `X` 一一对应。**

因此 **A/B 在源记录中的偏移就是 `+0x168` / `+0x16C`**（与槽同偏移）。
**这一环不需要额外证据 —— 它是"复制类型"的直接推论，而非假设。**

> ★ 这实际上把问题**化简**了：
> **只要能拿到源记录（0x238 字节）的原始字节，A/B 就在其 `+0x168/+0x16C`。**

## 3. 读取端复核（两端一致）

### 3.1 槽 `+0x168/+0x16C` 的地址算式

```
槽 k 基址      = mk + 0x7470 + k*0x238
槽 k +0x168    = mk + 0x75D8 + k*0x238      ← A
槽 k +0x16C    = mk + 0x75DC + k*0x238      ← B
```

### 3.2 mmbook 读取（`0x62F6F0`）

```
0062F736  mov ecx, [edi + 0x168]     ; A（edi = 槽基址）
0062F73C  mov [esi+0x3A048], ecx
0062F742  mov edx, [edi + 0x16C]     ; B
0062F748  mov [esi+0x3A04C], edx
```

### 3.3 accepted handler 读取（`0x632680`）

```
006326EF  mov eax, [esi + 0xE360]        ; k
006326F5  imul eax, eax, 0x238
006326FB  mov edx, [eax + esi + 0x75D8]  ; = A
00632702  cmp edx, [ebp + 8]
00632707  mov eax, [eax + esi + 0x75DC]  ; = B
0063270E  cmp eax, ebx                   ; ebx = [ebp+0xc]
```

### 3.4 宽度与转换

| 项 | 结论 | 证据 |
|---|---|---|
| A/B 宽度 | 各 **32-bit**；A 在低地址 | `mov edx,[...]` / `mov eax,[...]`（dword） |
| 二者关系 | 相邻 dword ⇒ 合计一个 **64-bit** 值 | 偏移差 = 4 |
| 字节序 | **无转换**（直接 `mov`，平台小端） | 全部为直接 dword 载入，无 `bswap`/`shl` 组合 |
| 中间转换 | **无**（`rep movsd` + 直接载入） | §2 / §3.2 / §3.3 |
