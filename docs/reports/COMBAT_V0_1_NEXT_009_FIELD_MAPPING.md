## 1. A/B 映射的**可执行取值程序**（本次新增：把"缺口"变成"一步读取"）

> 这是本次最有价值的产出：**一旦授权并采集，映射可在同一步读出**，
> 无需再追客户端解析逻辑。

### 1.1 依赖的既有已证事实（引用，不重复推导）

| 事实 | 来源 |
|---|---|
| `0x637950` 对源记录做**偏移保持的整块复制**（`rep movsd`, `0x8E` dwords） | NEXT-006 §2 |
| 预约槽 A/B = `mk+0x75D8/+0x75DC + k*0x238`（槽 `+0x168`/`+0x16C`） | NEXT-003/004 |
| mmbook 读 A/B 的字面值在 45 B 请求中可见 | NEXT-008 F1 |

### 1.2 取值程序（采集后按此执行，全部可复核）

```
输入: capture-21-5.out.log 中同一 conn_id 的 service=21 task=5 行（306 B hex）
      capture-21-5.in.log  中紧随的 service=6 task=14 行（45 B hex）

步 1  校验帧头:  u32(raw[0:4]) == len(raw) - 4        -> 必须 == 302
步 2  解密正文:  plain = AES-CBC-decrypt(aes_in, raw[10:26], raw[26:298])
                校验 u32(plain[0:4]) == 262 且 plain[4] == 1
步 3  定位对象:  inner = plain[5 : 5+262]
                obj   = inner[0x1A : 0x1A+236]              <-- 会话对象 236 B
步 4  取出 A/B:  从 mmbook 文本 "mmbook <A> <b64> <B>" 解析 A、B 的字面十进制
步 5  扫描对应:  在 obj(236 B) 中搜索 A 的编码，覆盖:
                  宽度  {1,2,4,8} 字节
                  字节序 {小端, 大端}
                  表示  {无符号, 有符号, 十进制 ASCII 串, hex ASCII 串}
                对每个命中记录: obj 内偏移 off
步 6  交叉验证:  对 B 重复步 5
                若 A 与 B 命中同一结构内的相邻/相关字段 -> 记为强候选
步 7  ★ 只记数值: 输出 "A 出现在 obj+0xNN（宽度/字节序/表示）"
                禁止输出"A = PLAYLIST_VERSION"之类语义断言
```

**★ 步 5–7 的关键价值**：NEXT-006 已证**偏移保持**，因此
**若 A 命中 `obj+off`，则 A 在预约记录中的偏移也是 `off`**
（记录与槽同偏移）——**映射直接成立，无需客户端解析逻辑。**

> ⚠️ 前提：会话对象（236 B）与"源记录（`0x238` B）"若非同一结构，
> 则偏移保持不适用。**这一点必须在步 5 命中后单独判定**
> （见 §1.3 的预判）。

### 1.3 「响应是否含完整 `0x238` 记录」的预判（**236 ≠ 568**）

| 量 | 值 |
|---|---|
| 会话对象（21/5 响应内） | **236 B** |
| 客户端预约源记录（`0x238`） | **568 B** |

**⇒ 预判：两者**不是同一结构**。因此：**
- ✅ 可以恢复"响应中的字段"；
- ⚠️ **不能**直接断言"该字段就是预约记录的 `+0x168/+0x16C`"——
  中间还差**客户端把会话对象映射进 `0x238` 记录**的那一步
  （即 NEXT-007 未定位的生产者）。

**⇒ 这修正/限定了 §1.2 步 7 的适用范围。**
**本次如实记录该限定，不夸大取值程序的效力。**

**⇒ accepted 体布局 = UNKNOWN（未变）。**

### 2.2 本次新增：同一插桩可一次覆盖 accepted

CAPTURE_PLAN 的插桩点（`lobby_server.py:1165`）位于**所有 `0x85` 应答**的公共路径上，

| 帧 | service/task | 用途 |

| **mmbook 应答** | **`6/14`** | ★ **accepted 的**实际**信封字节** |

**⇒ 授权后可在**同一次采集**中得到 accepted 的两种形态（应答 + 推送）的原始字节，
