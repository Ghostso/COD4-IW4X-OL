## 0. 结论先行（回答问题 1）

> **Q1：谁调用 `0x63794F`？**
>
> **答：唯一调用链为 `0x6379E0`（薄转发器）→ `0x63794F`。**
> **而 `0x6379E0` 本身不作为函数被直接调用 —— 它作为【回调指针】**被
> `0x62DE90` 注册到 `0x6292B0` 的 **timer id `0x32`**。

**完整链路（全部 CONFIRMED）：**

```
[注册] 0x62DE90  (主 vtable 0xDC7274 的 +0x024)
        0062DE9B  push 0x6379E0          ; ★ 回调
        0062DEA0  push 0x32              ; ★ timer id = 0x32 (= 50)
        0062DEA2  call 0x6292B0          ; 注册
[触发] (timer id 0x32 到点，由 0x7FA800 定时器泵触发)
        0x7FA9A7  lea  ecx, [ebp - 0x50]        ; 条目结构
        0x7FA9AA  push 0
        0x7FA9AC  push ecx                      ; ★ 第一参数 = 条目指针
        0x7FA9B0  call dword ptr [ebp - 0x20]   ; ★★ 回调被调用
        -> 回调第一参数 (=[ebp+8]) = 条目指针；第二参数 ([ebp+0xc]) = 0
[转发] 0x6379E0
        006379E3    mov eax, [ebp + 0x0C]      ; 回调的 arg2 (= 0)
        006379E6    mov ecx, [0x82E13FC]       ; ★ 匹配对象单例
        006379EC    push eax                   ; 第四参
        006379ED    mov eax, [ebp + 0x18]      ; ★★ arg6 = 源数组
        006379F0    push ecx                   ; 匹配对象
        006379F1    mov ecx, [ebp + 0x14]      ; arg5 = 记录数
        006379F4    call 0x637950              ; ★★★ 批量复制
[复制] 0x637950 (= 0x63794F 的正式入口)
        0063795D    mov dword [ebx+0x7230], 0  ; 槽计数清零
        00637997    rep movsd                 ; ★ 每记录 0x8E dwords = 0x238 字节
        00637989    lea edi, [ecx+ebx+0x7470] ; dst = 预约槽
        00637999    add dword [ebx+0x7230], edx
        006379A7    jne 0x637975
```

**⇒ `0x63794F` 直调者 = `0x6379E0`；`0x6379E0` 的唯一引用 = `0x62DE9B`（作为回调立即数）。**

## 1. 逐项证据

### 1.1 `0x63794F` 的入口与直调者（工作一.1）

| 项 | 值 | 证据 |
|---|---|---|
| 函数入口 | `0x637950`（`0x63794F` 是 `int3` 填充字节） | `0x63794F: cc 55 8b ec`；`0x637950: 55 8b ec 80` |
| **直接 `E8` 调用者** | **仅 1 处：`0x6379F4`** | `pe.calls_to(0x637950)` → `[0x6379F4]` |
| `0x63794F` 的 dword 引用 | **0** | 全镜像检索 |
| `0x637950` 的 dword 引用 | **0** | 全镜像检索（**不在任何 vtable**） |

### 1.2 `0x6379E0`（转发器）的引用（工作一.2）

| 项 | 值 | 证据 |
|---|---|---|
| 转发器入口 | `0x6379E0`（`0x6379DF` 是填充） | `0x6379DF: cc`；`0x6379E0: 55 8b ec` |
| **直接 `E8` 调用者** | **0** | `pe.calls_to(0x6379E0)` = 空 |
| **全镜像 dword 引用** | **仅 1 处：`0x62DE9C`**（`push 0x6379E0` 的立即数） | `pe.find_bytes(...)` → `[0x62DE9C]` |
| 该引用所在函数 | `0x62DE90`（主 vtable `0xDC7274` 的 **+0x024**） | `0xDC7298 = 0x62DE90` |

**⇒ 转发器`0x6379E0` 从不被"调用"，只被"作为回调传递"。这是"没有直接调用者"的原因。**

### 1.3 调用前的寄存器与栈参数恢复（工作一.2）

**`0x6379E0`（转发器）的入参 → 出参映射：**

```
006379E0  push ebp / mov ebp,esp
006379E3  mov eax, [ebp + 0x0C]        ; in: arg2
006379E6  mov ecx, [0x82E13FC]        ; 匹配对象单例
006379EC  push eax                     ; out: [ebp+0x0C] (第四参)
006379ED  mov eax, [ebp + 0x18]        ; in: arg6  ★★ 源数组
006379F0  push ecx                     ; out: [ebp+0x08] (第一参) = 匹配对象
006379F1  mov ecx, [ebp + 0x14]        ; in: arg5  ★ 记录数
006379F4  call 0x637950                ; ecx = 记录数；eax = 源数组
006379F9  pop ebp / ret
```

**`0x637950` 函数签名（由序言确定）：**

| 寄存器/栈 | 含义 | 证据 |
|---|---|---|
| `eax` | **源记录数组指针** | `0x637995 mov esi, eax` → `rep movsd` |
| `ecx` | **记录数** | `0x637969 test ecx,ecx / jle`；`0x63796D mov [ebp+0xc],ecx` |
| `[ebp+8]` | 匹配对象 | `0x637958 mov ebx, [ebp+8]` |
| `[ebp+0xC]` | 模式标志（byte） | `0x637953 cmp byte [ebp+0xc], 0` |

### 1.4 数组长度、记录数量与生命周期（工作一.4）

| 项 | 值 | 证据 |
|---|---|---|
| 单条记录字节数 | **0x238**（`0x8E` dwords） | `0x637990 mov ecx, 0x8E` + `0x637997 rep movsd` |
| 源数组步长 | **0x238** | `0x63799F add eax, 0x238` |
| 目的地步长 | **0x238** | `0x637983 imul ecx,ecx,0x238` |
| 记录数 | 循环计数 `[ebp+0xC]`（由入参） | `0x6379A4 sub [ebp+0xc],edx` / `0x6379A7 jne` |
| **每条的过滤条件** | `cmp dword [eax+0x124], 1` → `ja 0x63799F`（跳过往后仍 `add eax,0x238`） | `0x637975`/`0x63797B` |
| 槽计数写入 | `mov [ebx+0x7230], 0` 起始，逐条 `add` | `0x63795D` / `0x637999` |
| **生命周期** | 数组由**定时器条目**持有：`[条目+0x08]` = 数组、`[条目+0xC]` = 记录数、`[条目+0x28]` = 引用计数对象 | NEXT-005 §1（`0x7FA640`） |

**⇒ 数组的生命周期绑定在"定时器条目"上，随条目一起建立并在 `0x7FA450` 清理时释放。**

### 1.5 排除"仅因结构大小相同而误判"（工作一.5）

NEXT-005 曾把 `0x6379B0` 的循环列为"逐槽回调 `vtable+0x50`"候选。本次复核把它排除：

```
006379A9  mov  esi, [ebx + 4]          ; 通知链表头（与 accepted handler 0x632824 同构）
006379B0  lea  edi, [ebx + 0x7470]
006379B8  mov  eax, [ebx + 0x7230]
006379BE  mov  edx, [ecx]              ; vtable
006379C0  mov  edx, [edx + 0x50]
006379C6  push eax / push edi
006379C8  call edx                     ; 通知（参数 = 槽数组, 槽计数）
```

| 判据 | `0x63794F` 本身 | `0x6379B0` 循环 |
|---|---|---|
| 是否写槽数组 | **是**（`rep movsd` → `mk+0x7470`，`0x637997`） | **否**（只读 `[ebx+0x7230]` 与数组地址作为**参数**） |
| `rep movsd` | **有**（`0x637997`） | **无** |
| 与 `+0x168/+0x16C` 的关系 | 整块复制（含这两个偏移） | 无（不复制） |

**⇒ 二者仅共享 `0x238` 步长常量，`0x6379B0` 不是写槽路径。排除。**
