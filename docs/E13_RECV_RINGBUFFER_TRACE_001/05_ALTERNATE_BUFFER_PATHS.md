# 05 — 替代缓冲路径 / ALTERNATE BUFFER PATHS

> 只对已追踪函数中**实际出现**的缓冲区操作做有限归类。不做全客户端普查。
> 原始输出：`_data/out_recv_bodies.txt`、`_data/out_3level.txt`

## 2. 收包函数的输出缓冲（B1）去向

| 收包函数 | B1 容量来源 | 接收后去向 |
|---|---|---|
| `0x602430` | `[ebp+0xc]` | 长度写入 `[ebp+0x14]` out 参数；**无内部复制** |
| `0x775A50` | `[ebp+0xc]` | 直接 `ret 8` 返回；**无内部复制** |
| `0x775AB0` | `[ebp+0xc]` | 直接 `ret 8` 返回；**无内部复制** |
| `0x6B4DE0` | `[ebp+0xc]` | 错误码分派；**未见复制** |
| `0x6029A0` | 栈参数 | 交 `0x602760` → `0x60E5B0`（状态机） |
| `0x605220` | 栈参数 | 交 `0x606650`/`0x5FB510` |
| `0x1B0430` | 栈参数 | 通用 socket 事件处理 |
| `0x784F60` | 栈参数 | 交 `0x784B40` |
| `0x78772D` | 栈参数 | 交多个状态处理函数（含 `.tvm0`） |

**结论（DIRECT）：** B1 是**调用者所有**的缓冲；9 个函数中**没有**任何一个把数据复制进 B2（环形缓冲）。

## 3. B1 → B2 是否有任何已证连接

| 检查 | 结果 |
|---|---|
| 收包函数 3 层闭包（179 函数）内引用 `0x743DE9C` | **0** |
| 闭包内引用 `+0x30AF2C`/`+0x30AF30`/`+0x8048` | **0** |
| 闭包内调用 `0x3524F0` | **0** |

**结论（REFUTED，限定范围）：** 在“9 个收包函数各自 3 层静态调用图”范围内，**不存在** B1 → B2 的已证数据流边。

## 4. 是否发现独立的实时数据路径

| 候选 | 证据 | 裁定 |
|---|---|---|
| `0x6029A0` → `0x602760` → `0x60E5B0` 状态机 | `jmp [edx*4+0xA026D0]` + 20+ `call [ebp-0xd2c]` 函数指针 | **INFERRED**（独立的协议状态机，未闭合） |
| `0x605220` → `0x606650`/`0x6104D0` → `0x672460` | `call ebx` 间接 | **INFERRED**（未闭合） |
| `0x1B0430` 通用 socket 事件处理 | 30+ IAT 间接调用 | **INFERRED**（未闭合） |
| `0x78772D` → `.tvm0` (`0xDBEF28A`) | 直接 `call` | **BLOCKED**（混淆边界） |

**说明：** 以上均为“**可能存在**第二条路径”的候选，但**均未定位到其下游消息入口**。按停止条件第 4 类（间接分派/混淆边界）登记 BLOCKED。

## 5. 未发现范围（明确限定）

- **未发现**：收包函数 3 层闭包 → 环形缓冲 B2 的任何边。
- **未发现**：B1 被复制进任何 3 MB 级共享缓冲。
- **未做**：全客户端缓冲普查（超出本轮范围）。
- **未排除**：经未解析间接分派（`0x60E5B0` 函数指针、`.tvm0`）到达 B2 或另一缓冲的可能。

## 6. 裁定

| 项 | 裁定 |
|---|---|
| B1 由调用者所有 | **PROVEN** |
| B2 = 发送序列化暂存（非接收） | **PROVEN**（`03`） |
| B1 → B2 已证边 | **REFUTED（限定范围）** |
| 独立实时路径 | **INFERRED（候选，未闭合）** |
| 是否完成替代路径定位 | **BLOCKED** |
