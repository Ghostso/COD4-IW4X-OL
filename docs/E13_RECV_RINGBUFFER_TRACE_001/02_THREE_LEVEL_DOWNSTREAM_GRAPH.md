## 2. 三层闭包对环形缓冲全局的引用（决定性负证据）

把 9 个收包函数各自 3 层下游取并集，共 **179 个函数**。

在该 179 个函数范围内，扫描以下全局/偏移的引用：

| 符号 | 含义 | 闭包内命中 |
|---|---|---|
| `0x743de9c` | 环形缓冲所属对象指针 | **0** |
| `+0x30AF2C` | 写游标 | **0** |
| `+0x30AF30` | 读游标 | **0** |
| `+0x8048` | 环形缓冲基址 | **0** |

（全 `.text` 范围内共 196 处引用，其中 **0** 处落在该闭包内。）

**这是决定性证据：收包侧三层闭包与环形缓冲**完全不相交**。**

## 3. 逐函数下游（关键边）

### R1 `0x1B0430`（14 个下游）
直接下游：`0x74A135`、`0x750900`、`0x750850`、`0x1B0410`、`0x1B0476`…（内存/错误处理工具）
**间接调用密集**：`call [0xbae484]`、`[0xbae494]`、`[0xbae184]`、`[0xbae508]` 等 30+ 处 IAT 间接调用。
→ 这是**通用 socket 事件处理器**，非业务解析器。

### R2 `0x6B4DE0`（2 个下游）
`0x749B31`（安全 cookie 检查）、`0x03A7C0`。
**间接**：`call [0xbae50c]`（recvfrom）、`jmp [ecx*4+0xAB4F50]`（错误码跳转表）、`call [0xbae4a0]`。
→ 错误码分派封装。

### R3 `0x775AB0` / R7 `0x775A50`
**0 个下游**。纯 `recv`/`recvfrom` 直通封装（`ret 8`）。
→ 虚表项，由对象分派。

### R4 `0x602430`
**0 个下游**。`recv` → `cmp eax,-1` → 错误映射 → 写 out 参数。
→ 最薄的 `recv` 封装。

### R5 `0x6029A0`（9 个下游）
`0x60FB00`、`0x602760` → `0x60E4A0`/`0x60E500`/`0x602600` → `0x60E5B0`/`0x6025A0`。
**间接**：`0x60264A jmp [edx*4+0xA026D0]`（状态机跳转表）；`0x60E5B0` 内 20+ 处 `call [ebp-0xd2c]`（**函数指针**）、`call ebx`。
→ **这是唯一有实质下游逻辑的收包函数**，但下游是**协议状态机**（跳转表 + 函数指针），仍未见环形缓冲。

### R6 `0x605220`（7 个下游）
`0x606650` → `0x6060F0`/`0x606110`；`0x5FB510` → `0x6104D0` → `0x672460`。
**间接**：`0x6066AA call ebx`。
→ 另一协议处理分支。

### R8 `0x784F60`（4 个下游）
`0x03A7C0`、`0x784B40` → `0x3622AC`。
→ 错误/清理路径。

### R9 `0x78772D`（多下游）
`0x750980`、`0x74BEE0`、`0x74FF60`、`0x74A1CB`、`0x754780`、`0x787CD0`、`0x74BFA0`、`0x787920`…
**间接**：`0x787982 call 0xDBEF28A`（`.tvm0` 区）、`0x787B50 jmp 0x787F20`。
→ 复杂状态处理；含 `.tvm0` 调用。

## 4. 间接调用登记（不闭合）

| 站点 | 形式 | 目标来源 | 是否闭合 |
|---|---|---|---|
| `0x60264A` | `jmp [edx*4+0xA026D0]` | 状态机跳转表 | 表内容可枚举，但需运行时 `edx` |
| `0x60E5B0` | `call [ebp-0xd2c]` ×20+ | **栈上函数指针** | **不闭合**（来源未定） |
| `0x60E5B0` | `call ebx` ×4 | 寄存器 | **不闭合** |
| `0x6066AA` | `call ebx` | 寄存器 | **不闭合** |
| `0x787982` | `call 0xDBEF28A` | `.tvm0` 区 | **不闭合**（混淆边界） |
| `0x6B4E68` | `jmp [ecx*4+0xAB4F50]` | 错误码表 | 表可枚举 |

**纪律：** 以上间接目标**不**计为已闭合调用边。

## 5. 裁定

| 项 | 裁定 |
|---|---|
| 3 层内到达 `0x3524F0` | **未发现**（限定范围：9 函数各自 3 层） |
| 3 层内引用环形缓冲全局 | **0 处**（179 个函数闭包内） |
| 收包侧与环形缓冲是否相交 | **REFUTED**（两者在静态调用图上不相交） |

| 停止条件 | 命中第 3 类（三层上限）与第 4 类（间接/混淆边界） |
