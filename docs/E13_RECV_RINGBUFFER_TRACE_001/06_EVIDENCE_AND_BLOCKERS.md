## 2. 阻断登记

### BLK-13-1：`0x60E5B0` 的函数指针来源

| 项 | 内容 |
|---|---|
| 缺口 | `0x6029A0` 下游 `0x602760`→`0x60E5B0` 内 20+ 处 `call [ebp-0xd2c]` 与 `call ebx`，目标未定 |
| 已排除 | 非 IAT 调用（不在导入表） |
| 替代解释 | ① 协议处理器注册表；② 状态机回调数组；③ 运行时构造 |
| 最小下一步 | 回溯 `0x60E5B0` 入口处 `[ebp-0xd2c]` 的赋值点 |
| 范围 | `0x60E5B0` 入口前 100 字节 + 其调用者 `0x602760` |

### BLK-13-2：`0x78772D` 的 `.tvm0` 调用

| 项 | 内容 |
|---|---|
| 缺口 | `0x787982 call 0xDBEF28A` 落入 `.tvm0` 混淆区 |
| 已排除 | 非原生 `.text` |
| 替代解释 | 混淆后的业务逻辑 |
| 最小下一步 | 依赖 E-06 的 `.tvm0` 解码（当前不可静态解析） |
| 范围 | 不扩大（停止条件第 4 类） |

### BLK-13-3：虚表实例化路径

| 项 | 内容 |
|---|---|
| 缺口 | `0x775A50`/`0x775AB0` 是 `.rdata 0x898588/0x898590` 虚表项，但实例化与调用点未定位 |
| 已排除 | 无直接调用者 |

| 最小下一步 | 定位写入 `.rdata 0x898588` 虚表的构造函数 |
| 范围 | `.rdata` 虚表附近 + 其构造者 |

### BLK-13-4：收包闭包内未解析的间接调用

| 项 | 内容 |
|---|---|
| 缺口 | 闭包内共 100+ 处间接 `call`/`jmp`（IAT 除外） |

| 最小下一步 | 逐个回溯寄存器来源（超出 3 层上限） |
| 范围 | 停止条件第 3 类 |
