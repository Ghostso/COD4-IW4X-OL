## 3. 关键结构发现：分层网络抽象（虚表分派）

`0x775A50`/`0x775AB0` 是**虚表项**（`.rdata` 中的函数指针表）：

```
.rdata 0x898580: 0xb75940 0xb75a00 [0xb75a50] [0xb75a80] [0xb75ab0] 0xb75af0 ...
.rdata 0x898588: [0xb75a50] [0xb75a80] [0xb75ab0] 0xb75af0 ...
.rdata 0x898590: [0xb75ab0] 0xb75af0 0xb75b30 ...
```

**含义（DIRECT）：** `0x775A50`（`recv`）与 `0x775AB0`（`recvfrom`）是同一 vtable 中的相邻槽位——这是**平台网络抽象层**（如 socket 实现族）的虚方法，由 `ecx` 指向的对象实例分派。

`0x1B0430` 与 `0x6029A0` 也仅通过数据指针被引用（`.text@0x1B007F`、`.text@0x601DF8`），属同类间接注册。
