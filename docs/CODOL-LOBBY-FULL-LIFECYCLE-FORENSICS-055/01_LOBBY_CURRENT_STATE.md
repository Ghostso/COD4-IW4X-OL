## 3. 大厅"能做什么 / 不能做什么"（面向使用）

**能做**
- 登录、拉档案、拉 playlist 表、拉商城
- 看到模式列表（因为 10/21 的 playlist 表给全了）
- 建房、发房间状态
- 点"开始"触发 mmbook/mmstart

**不能做**
- 房间内点"准备"（无反应）
- 房间成员列表（没有该协议）
- 房间 UI 动态更新（推送不被消费）
- 通过房间入口进入战斗服
- 通过 PvE 入口进入战斗服（当前配置下）
