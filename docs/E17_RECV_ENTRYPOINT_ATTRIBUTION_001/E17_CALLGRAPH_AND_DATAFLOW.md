## 4. 未闭合边界（BLOCKED）

| 边界 | 说明 |
|---|---|
| 0x783F00 的无直接调用者 | 经虚表 `.rdata 0xC9F794` 分派（槽位 [4] = 0x784000，非 0x783F00）；真实分派路径需对象实例信息 |
| 0xA84CE0 的语义 | Demonware 对象交付点；未展开（超出本轮范围） |
| 0x6ABBC0 / 0x6B3310 的会话状态机 | 未展开（Demonware 内部） |
