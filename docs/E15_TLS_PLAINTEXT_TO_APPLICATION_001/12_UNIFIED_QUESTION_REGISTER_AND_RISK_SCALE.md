## 3. 风险加权解决率计算

**总权重** = 8+8+8+8+8+5+5+5+5+3+8+8+5+3+3+1 = **91**

**加权得分** = Σ(权重 × 解决度)：
- Q-09..Q-14（PROVEN，权重 5+3+8+8+5+3=32）→ 32 × 1.0 = 32
- 其余 10 项 BLOCKED（权重 59）→ 0
- **加权得分 = 32**

**风险加权解决率 = 32 / 91 = 35.2%**

## 4. 关键解读

| 观察 | 说明 |
|---|---|
| 高权重项（I4）共 6 项（Q-01..05, Q-11, Q-12）| 其中 4 项 BLOCKED（Q-01..05），2 项 PROVEN |
| I4 层解决度 | (8+8)×1.0 / (8×6) = 16/48 = **33.3%** |
| 传输/消息/Gamestate 实时链 | **全 BLOCKED**（Q-01..05） |
