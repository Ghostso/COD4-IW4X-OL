## BLK-15-1：0x67F5F0 调用者的函数边界

| 项 | 内容 |
|---|---|
| 缺口 | 0x67F5F0（通用 SSL_read 调用点）的所属函数无标准 prologue，fs() 启发式误判为 0x631E10（跨 317 KB） |
| 已排除 | 非 IAT 调用；确为 0x672460 第二调用点 |
| 替代解释 | 1) 该函数由编译器尾部合并；2) 属另一个模块（无 epilogue 分离） |
| 最小下一步 | 用 CFG 而非 prologue 启发式重建 0x67F000 到 0x680000 边界 |
| 范围 | 0x67F000 到 0x680000 |

## BLK-15-2：更新模块与游戏模块的调用边界

| 项 | 内容 |
|---|---|
| 缺口 | 已知 TLS/libcurl 属更新模块，但游戏协议走哪个传输栈未定位 |
| 已排除 | 同进程内存在明文 UDP 栈（recv/recvfrom IAT 锚点 + 9 收包函数） |
| 替代解释 | 1) 游戏协议走明文 UDP（与 IW4X/CoD4x 一致）；2) 走另一条未定位的 TLS 会话 |
| 最小下一步 | 在 0x1B0430/0x78772D 路径中寻找游戏消息特征串/常量 |
| 范围 | 0x1B0430、0x78772D 各自三层 |

## BLK-15-3：0x1B0430 的 30+ IAT 间接调用

| 项 | 内容 |
|---|---|
| 缺口 | 0x1B0430 内 30+ 处 call [0xBAE...]，多数为 socket API；其业务分支目标未定 |
| 已排除 | IAT 目标可从导入表解析（已做） |
| 替代解释 | 通用 socket 事件循环 |
| 最小下一步 | 解析其事件分支（0x1B086D / 0x1B0991 / 0x1B0A25 / 0x1B0ADF） |
| 范围 | 0x1B0430 |

## BLK-15-4：0x78772D 的 .tvm0 边界
