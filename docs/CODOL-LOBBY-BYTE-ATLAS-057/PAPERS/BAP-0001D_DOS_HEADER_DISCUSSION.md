# BAP-0001D — 讨论：MS-DOS 头的一段"无定义常量"

对应正论文：`BAP-0001_DOS_HEADER.md`
本次讨论重点：`0x1C–0x23` 与 `0x28–0x29` 的非零值究竟是语义还是噪声。

---

## 1. 我的判断可能错在哪

正论文给出了两个断言，都可能错：

**断言 A**：`0x1C–0x23` 的 `00 70 77 00 48 00 00 00` 是链接期常量，无语义。
**断言 B**：`0x28` 的 `0x9E97` / `0x2A` 的 `0x6098` 是确定性填充，可当构建指纹。

### 替代假设 H1：`0x1C` 段其实是残留的重定位偏移

DOS 头 `0x1C` 在 *旧版*（DOS 3）布局里是 `e_res`，但在某些 Borland/Watcom
链接器里被复用。若 `0x00777000` 是某个重定位目标 RVA，那么
`e_lfarlc = 0x40` 指向的重定位表就应该有意义。

**反证**：读 `0x40` 起 16 字节：

```
0040  0e 1f ba 0e 00 b4 09 cd 21 b8 01 4c cd 21 54 68
```

这是 `push cs / pop ds / mov dx,0x0EB4 / mov ah,9 / int 0x21 / mov ax,0x4C01 /
int 0x21 / "Thi..."` —— 标准 MS-DOS `print-string-and-exit` stub，
**不是重定位表**（重定位表每项 4 字节 `{off:2, seg:2}`，这里是 x86 指令）。
且 `e_crlc = 0` 声明零个重定位项。⇒ **H1 被反证**。

### 替代假设 H2：`0x28` 的 `0x9E97` 是时间戳的一部分

`e_res2` 常被某些工具塞入时间戳。若 `0x9E97_6098` 是 Unix 时间，
解出来是 2106 年（明显不合理）；若是 DOS 日期时间包：
`date = 0x6098 → 年=0x30=48+1980=2028, 月=12, 日=24`；
`time = 0x9E97 → 时=0x1F=31`（非法，>23）。⇒ **H2 被反证**（E3：字段越界）。

### 替代假设 H3：这些字节在解包过程中被覆盖

我们的镜像是从活进程内存转储提取的。若加壳器把 DOS 头当成写保护区，
解包后的字节可能与磁盘原文件不同。

**反证**：`e_lfanew = 0x128` 必须与磁盘版一致，否则 Windows 加载器
无法启动原始 EXE。而原始 EXE 确实被启动过（2020 年、以及我们每次
用 `run_frozen_chain_once.py`）。⇒ `e_lfanew` **必然未被改动**（E3）。
但这不直接证明 `e_res` 段没被改动。

**这是一个真实的风险，不是可以糊过去的**：如果加壳器把 `0x1C–0x3B`
当成自己的暂存区，那这些字节就是**壳的残留**而不是链接器指纹，
把它们当"构建指纹"就会在换版本时失效。

---

## 2. 每个替代假设的证据

| 假设 | 判据 | 结果 |
|---|---|---|
| H1 `0x1C` 是重定位表线索 | `0x40` 处是 DOS 代码而非重定位表；`e_crlc=0` | **否** |
| H2 `0x28` 是时间戳 | DOS 日期解出 2 月 32 日 / 31 时，越界 | **否** |
| H3 解包破坏该段 | 无直接证据；`e_lfanew` 未变只覆盖一个字段 | **未决** |

---

## 3. 若判断成立，下游会怎样

- 若断言 A/B 成立（链接器指纹）：这些字节可作为"这份镜像来自哪个链接器"
  的旁证，**与 Rich header（BAP-0002）互相印证**。Rich header 已给出
  VS2010 SP1 为主（`prod 170 build 40219` 共 983+843+748 个对象）。
  两处独立指纹一致 ⇒ E3。
- 若 H3 成立（壳残留）：BAP-0001 §2 表格中 `e_res` 两行应标为
  "不可信 / 壳残留"，且不能用于任何后续推导。**不影响任何其它结论**，
  因为没有任何代码读这些字节。

---

## 4. 最小可证伪实验

**不需要启动游戏。** 直接对比磁盘原始 EXE 的同一段：

```powershell
$disk = "D:\BaiduNetdiskDownload\使命召唤OL\...\<原始 EXE>"
# 读前 0x40 字节，与镜像前 0x40 字节做 diff
```

- 若完全相同 ⇒ H3 被反证，断言 A/B 成立。
- 若不同 ⇒ H3 成立，但只影响本段 12 字节的定性。

（该实验将在 BAP-0003 之后统一做一次"磁盘 vs 内存镜像全头部 diff"，
避免逐篇重复读磁盘。）

## 5. 本次讨论改变了什么

- 正论文 §2 中 `e_res2` 两行从"确定性填充，可当构建指纹"**下调**为
  "未决：链接器指纹或壳残留，待磁盘对比"。
- 判据等级从 E1 保持（值本身是 E1），但**语义定性从 E2 降为未决**。
- 新增一条全局纪律：**凡"无定义字段"的语义结论，必须有两处独立印证，
  否则只能记录数值**。这条纪律已并入 `00_PAPER_SYSTEM.md` §3 的反证要求。
