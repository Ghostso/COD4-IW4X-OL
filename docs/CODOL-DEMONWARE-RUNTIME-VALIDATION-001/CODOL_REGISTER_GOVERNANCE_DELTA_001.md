### 3.2 裁决建议（三选一，需项目负责人批准）

**建议 A（推荐）：Q-44 计入分母，统一采用全量逐项口径。**
- 理由：Q-44 是一个**真实且仍未被闭合并行解决**的高影响问题（INFERRED，0 分），
  把它从分母剔除会**高估** I4 完备率；保留在分母符合"不通过删除问题改善比例"的纪律。
- 后果：I4 权重 376、I4 完备率 57.87%；建议同时更正报告链的历史 I4 值（以增量方式登记，不回改原文）。

**建议 B：Q-44 与 Q-45/Q-53 合并，从分母扣除 8。**
- 理由：Q-44（载荷对象协议归属）与 Q-45（HMAC 调用方向）、Q-53（0x85 入站方向）同属"该对象方向/归属"问题，
  存在**概念重叠**（见 §4）。
- 后果：I4 权重回到 368、I4 完备率 59.13%；需在登记簿显式记录合并关系（如同 Q-15→Q-24 的处理）。
