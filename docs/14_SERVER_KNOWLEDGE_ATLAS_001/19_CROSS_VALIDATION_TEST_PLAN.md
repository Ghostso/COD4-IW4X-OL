## E-04 的方法学要点（必须保留）

- 映射公式：`file_offset = PointerToRawData + (RVA − VirtualAddress)`（区段表存 **RVA**）。
- 已用交接值双向校验：`RVA 0x1AC1D0 → off 0x1AB5D0` ✔、`RVA 0xA2E50 → off 0xA2250` ✔。
- `.text` E8/E9 扫描**可靠性 95.1%**（落真实函数入口率）→ 0 命中是**强负面信号**。
- `.tvm0` E8/E9 落入口率 **0.0%** → 其命中为**噪声**，**不得**用作调用者证据。
- `.data` 99.86% 不在文件内 → 搜索**不完备**，因此结论**只能**是 `BLOCKED`，**不能**是 `REFUTED`。
