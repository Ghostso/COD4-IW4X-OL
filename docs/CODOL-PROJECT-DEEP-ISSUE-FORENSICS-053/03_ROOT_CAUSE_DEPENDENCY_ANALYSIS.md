## 4. 关键路径

```
E1 → E2 → E3  （决定 0020 的自变量）
        │
        ├─ 若是地图 ──→ 修 lobby 的地图一致性 ──→ 连接恢复
        │
        └─ 若是入口 ──→ 0009/0012 ──→ 房间可用 ──→ 连接恢复
```

**两条分支的成本差异巨大**：
- 地图分支：改 `lobby_server.py` 一处（S）
- 入口分支：要解决 0009（可能无解，见 ISSUE-0009 三重封死）

⇒ **这个实验的价值在于：它可能是"用一次小改动绕开一个无解问题"的唯一机会。**

## 5. 一个必须写下来的风险

如果 E2 证明"地图是根因"，那么最自然的修复是：
**让 lobby 永远回 `coop_train_mp_firingrange`**。

但这意味着：

- 只能玩这一张图（本地已解包的 5 张里唯一验证过能连的）
- 与"换图/剧情不同关卡"的产品目标冲突
- 是**绕过**而不是**解决**

必须由用户决定是否接受这个约束。本审计不代替这个决定。
