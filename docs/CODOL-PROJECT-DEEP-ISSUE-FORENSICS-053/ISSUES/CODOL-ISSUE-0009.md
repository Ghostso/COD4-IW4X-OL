## 02. 问题的精确定义

**预期行为**
点击"准备" → 客户端本地状态变为 Ready → 发出一条上行（形如 `0B/4 setRoomData` 的一个 ready 批次 或专用 ready 消息）→ 服务端收到并广播给房间成员。

**实际行为**
- 点击后**本地 UI 状态也不变**（不是"发了但没回"，是"什么都没发生"）
- 该轮 `11/4` 上行只有 4 条，**没有一条是准备**

**偏差**
连客户端本地的状态机都没有推进。

**失败边界（逐层）**

| 层 | 结论 | 证据 |
|---|---|---|
| 点击是否被 Flash 接收 | **UNKNOWN** | 无 UI 日志 |
| Flash 是否调用 Scaleform 回调 | **UNKNOWN** | `.gfx` 加密 |
| C++ 侧是否有处理器 | **UNKNOWN** | `AS_*` 类名存在但无 COL/零引用 |
| 本地状态是否变化 | ❌ 用户观察"连已准备状态都不变" | 用户报告 |
| 是否发出上行 | ❌ 该轮 4 条上行无准备 | `ONCE_20261028_225645` 日志 |

**失败边界一句话**：事件在**客户端 UI 内部**就被丢弃了，还没到网络层。
