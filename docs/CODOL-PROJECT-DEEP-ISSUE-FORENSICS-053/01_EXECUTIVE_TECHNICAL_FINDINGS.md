### 2.4 服务端实现

上一轮用 `grep` 找到 5 个"无调用者"的函数族。本批次按任务要求做了完整核查
（取地址 / 回调槽 / 注册表 / 构建路径 / 主循环 / 网络输出 / 测试），**结论不变且更强**：

- 全部 9 个函数**没有任何间接调用路径**（对它们取地址的代码 0 处）。
- 额外发现：`codol_pmove_single` 不只是没人调，它**独占**了跳跃逻辑，
  所以跳跃在网络路径上根本不存在（ISSUE-0028 的代码级根因）。
- `replication` 层是**第二套快照机制**，实际发包走 `snapshot.c`，两者并行且后者未用。
