# 最小实验：E6

## 步骤

1. 用当前正式 kit 启动客户端（需授权）。
2. 用 CODOLServer/_mainline/dump_earliest.py <outdir> 200 6 抢早期句柄。
3. 扫描 vtable 0x00DC78F0 的实例数。
4. 同转储扫描 0x00DC795C 作阳性对照。

## 预期结果

若 H0 成立，0x00DC78F0 实例数 ≥ 1。

## 判断标准

| 观察 | 结论 |
|---|---|
| 0x00DC78F0 ≥ 1 | H0 成立；本 Issue 作废 |
| 0x00DC78F0 = 0 且 0x00DC795C ≠ 0 | 存在第二条创建路径（重大发现） |
| 两者都为 0 | 该次转储没覆盖到建房时刻 |

## 前置条件

- 转储窗口需覆盖建房时刻（t≈80–100 s），而早期窗口约 t≈24 s —— 这是已知障碍

## 风险/注意

若窗口不重叠，需要先解决 ISSUE-0045 的转储可行性。
