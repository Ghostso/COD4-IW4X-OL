## 五、当前真正的缺口

游戏进程 14220（另一次干净采集）的全部 connect 目标只有：

```
101.72.248.61:80/443   TenProtect / BugTrace
121.29.3.105:443       intldlgs.qq.com (TLS)
127.0.0.1:58xxx        CEF 回环
116.130.224.66:8000    UDP IIPS
```

**没有大厅/Blaze 连接。** 而链接栈里存在完整的 Demonware/Blaze 代码
（`DW_LOBBY_CONNECT`、`BD_LOBBY_*`、`dwLogonStart`），说明大厅协议栈是
游戏内建的，但地址/凭据来自它上游的**某个平台服务**。

最可能的来源（尚未证实）：

1. **TQMCenter / TenProxy / CrossProxy** —— 平台层，可能负责下发登录票据/地址
2. **IIPSHostApp** —— 策略与资源通道
3. **加密的 `players\config_mp.cfg`** —— CoD dvar 文件，可能含 `dwlobbyhost` 之类
4. **GameRpcs.dll / TenRpcs.dll** —— 腾讯 RPC 层
