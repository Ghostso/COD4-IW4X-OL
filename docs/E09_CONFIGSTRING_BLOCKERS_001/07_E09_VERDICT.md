# 07 — E-09 裁定 / VERDICT

> 任务要求：把三个阻断项分别升级为 **PROVEN / REFUTED / BLOCKED**，并提供可复核证据；不得以"搜索完成"代替解决。
> 只读静态分析。原始输出：`_data\out_a01..out_c09.txt`；脚本：`_tools\*.py`。

## 1. 三个阻断项的裁定（任务 A/B/C）

| 任务 | 阻断项 | 裁定 | 一句话证据 |
|---|---|---|---|
| **A** | 客户端 Configstring body 字段消费顺序 | **PROVEN** | 客户端 `0xA2660` 与服务端 `0xA0468` **逐字段一致**（count1=2B；13-bit 索引；11/10-bit 计数；10-bit 值；A3=10/7/4/n×12；上界 `0x1DD7`；区间 0..0x13 跳过 0x12） |
| **B** | `count1` 实际编码宽度 | **PROVEN = 2 字节（16 位）**；8 位 **REFUTED** | `0x994FC` 中 `ecx` 三重用法=字节数；客户端 `push 2` → `MSG_ReadData` + `movsx word ptr` |
| **C** | `0x06` 位边界、对齐与终止语义 | **服务端 PARTIAL（写入侧已闭合）／客户端 BLOCKED** | 位游标在字节边界**强制重同步** `bitpos=used*8`（0x9961F）；A1 字符串不动 bitpos；客户端 `0xA2660` **无 `0x06` 读取** |

## 2. 任务 A 明细（已定位 / 候选 / 无法分类）

**已直接定位（PROVEN）：**
```
0xA2660  ← 客户端 Configstring body 读取器
  ├─ 0x1AC1D0 MSG_ReadData(...,2)      @ 0xA26B2   读 count1
  ├─ 0x1AC670 MSG_ReadBits             @ 0xA26F4/0xA276C/0xA27A8/0xA27D7/0xA2879/0xA28A9
  ├─ 0xA25F0  （NUL 终止字符串处理）      @ 0xA2751
  └─ 0xA2480  （A3 记录 10/7/4/n×12）    @ 0xA28E0
```
**旁证：** 字符串 `"** %i %i"`(0xCB8334)、`"* %i"`(0xCB8344)、`EXE_CONFIGSTRINGMISMATCH`(0xCB835C)、`gamestateupdate %d`(0xCB8378) 同组。

**仅共享位读取原语的候选（BLOCKED）：**
`0xA0D40`、`0xA1290`、`0xA16B0`、`0xA1AE0`、`0xAA332`、`0xAAD80`、`0x6D5D0`、`0x1AD3A0`…`0x1AF4E0`（19 个）——共 33 个含 `MSG_ReadBits` 调用的函数中的其余部分。

**无法分类（BLOCKED）：**
读取 `0x04`/`0x06` 的**外层消息分派器**；`0x02`→`0xA2E50`；`.tvm0` 内路径。

> **纪律遵守：** 未找到外层分派器**不等于**客户端不支持 —— 记为 `BLOCKED`。

## 3. 任务 B 明细

- `0x99566` 包装器把 `ecx=2` 传给核心 `0x994FC`；核心中 `ecx` **同时**是（a）拆字节循环次数、（b）`MSG_WriteData` 的 `len`、（c）`value >> 8k` 的步长索引 → **字节数**，无其它解释。
- `0x99566` 在服务端**仅**用于此类计数写入，无"位数"用法。
- 客户端**独立**读 2 字节并按 16 位有符号解释。
- 8 位假设的唯一来源（内联 `"* %u"`）经复核为 **`snprintf` 文本用途**，不是线格式位宽。
- **后果：** `22_SERVER_START_GATING_AUDIT.md` 中"count1 必须参数化"的建议**不再必要**。

## 4. 任务 C 明细

| 子项 | 裁定 |
|---|---|
| body 起点到 `0x06` 的累计位可算 | **是**（模型：44/53/61/**72**/129 — 依输入） |
| 写入原语是否字节对齐 | **是**：`bitpos%8==0` ⇒ `bitpos = used*8`（0x9961F–0x9962E） |
| 对齐发生点 | `MSG_WriteBits` 增长块 |
| A1 字符串是否占位 | **否**（`0x99651` 无 `[msg+0x10]` 访问） |
| `0x06` 是否总字节对齐 | **否**（可对齐但不必然） |
| 客户端读取端独立证据 | **无**（`0xA2660` 循环结束即 `ret` @0xA2975） |
| 端到端终止语义 | **BLOCKED**（按任务规定，缺读取侧不得标 PROVEN） |
| `0x06` 跨上下文等同 | **禁止**（configstring 0xA0997 / gamestate 0xA22F8 / snapshot 内部 0xA4CAF / 外层选择器 0x87104 分别登记） |
