## 五、★★★ 这对 P4 补丁的影响评估

### 补丁前后的差异

```
补丁前：
  r != 0 → g_state = 3（写 0x82CA530）→ 返回 0
  r == 0 → [esi+0x5E8] = 3           → 返回 1

补丁后：
  永远 → [esi+0x5E8] = 3             → 返回 1
  （0x82CA530 不再被写）
```

★★★ **⇒ 补丁的唯一副作用是 `0x82CA530` 不再更新。**

★★ **而 `0x82CA530`**没有任何读者** ⇒ **副作用为零**。**

★★★ **⇒ P4 补丁是**完全安全的**（无未预期影响）。**

★ **这是一个重要结论：`nt10.py` 的补丁设计**考虑到了这一点**（或者恰好无害）。**
