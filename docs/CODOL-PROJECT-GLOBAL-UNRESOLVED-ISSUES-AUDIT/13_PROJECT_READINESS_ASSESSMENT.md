- **L0 代码已实现**：函数存在，能编译

- **L4 可玩战斗验证**：同 PID 内完成 进图→移动→开火→命中→伤害→死亡→复活→计分→结束

## 四、当前"距离可操控画面"的真实距离

用户问的是"什么时候能在游戏里走两步"。严格回答：

```
已经成立：客户端能进大厅、能建房、能进图（历史）、能发 usercmd、能被服务端解析
缺失的：  能连上战斗服（当前环境）→ 能拿到位置权威 → 能看到实体
```

**最后一步"能连上战斗服"目前不成立。** 所以严格说：

> 当前项目**无法复现**"进入地图"这一历史成绩；
> 需要先解决 ISSUE-0020（+0021/0074 两个最便宜的候选根因）。
