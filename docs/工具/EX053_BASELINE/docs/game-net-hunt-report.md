## 【WKNet 与 .tvm0 的关系】

**两条独立结论，必须分开读。** [已证]

1. **`.tvm0` 是「密钥化分支的派发器」，不是普通代码节。**
   节内**分支立即数被加密** ⇒ **该节内部所有 `rel32` 边一律不可信**，不能按相邻关系推调用图。
   这是前窗用 780 个真 IAT 调用点反查得到的结论。

2. **780 个真 IAT 调用点（从 .tvm0 出发）只映射到 TP3 类安全面**，
   其中**网络相关仅 5 个点**，且**全部属 WKNet 选路面**。
   ⇒ **没有任何一个 .tvm0 调用点指向游戏 netcode。**

3. **WKNet_singleton + 0x34（地址选择）的写入落在 `.tvm0` 内** —— 与结论 2 一致：
   **.tvm0 承担的是「安全面 + 选路接入」的派发，不是游戏收发包。**

★ **不得由「.tvm0 里有网络调用点」推出「.tvm0 是游戏网络层」** —— 那 5 个点全是 WKNet。
