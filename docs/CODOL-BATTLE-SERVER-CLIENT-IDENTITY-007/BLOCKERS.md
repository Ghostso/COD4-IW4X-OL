# BLOCKERS — 目标客户端身份缺失阻塞项

**任务：** CODOL-BATTLE-SERVER-CLIENT-IDENTITY-007
**日期：** 2026-10-13（Asia/Shanghai）

---

## 0. 总体阻塞

**BLK-007-00 — 本地没有可归属于 CODOL 3.9.9.7 的客户端映像。**
本项是其余全部阻塞的根因。在解除前，任何针对 3.9.9.7 的协议字段、包长、偏移或 snapshot 实现都缺少目标样本依据。

---

## 1. 阻塞清单

### BLK-007-01 — 3.9.9.7 客户端二进制缺失（P0）

- 结论：工作区与已授权库外目录中均未发现 3.9.9.7 客户端。
- 现状证据：实际存在的客户端仅为 1.1.1.13、3.3.3.3 族（FileVersion 1649370）、2.6.9.7；`3.9.9.7` 字符串仅出现在既有报告文本中。
- 缺少的文件：目标版本的 `codoMP_client_shipRetail.exe`（或等价命名的 PE 映像）及其主 DLL。
- 最小解除证据：一个具有明确来源说明、且其版本资源/清单/SHA-256 可复核的 3.9.9.7 客户端映像。
- 影响：无法建立目标版本入口、模块、RVA 与函数锚点。

### BLK-007-02 — 3.9.9.7 版本清单 / 哈希登记缺失（P0）

- 结论：没有把任何本机文件与 3.9.9.7 关联的 manifest、`games.json`、启动器配置或审计登记。
- 缺少的证据类型：版本资源 dump、官方清单、来源说明 + 完整 SHA-256。
- 最小解除证据：一份声明 `version = 3.9.9.7` 且哈希与目标文件一致的清单，或等效的用户来源确认。
- 影响：无法把“某文件属于 3.9.9.7”提升到 `CONFIRMED`。

### BLK-007-03 — 3.9.9.7 真实连接抓包缺失（P0）

- 结论：本机全部 `pktmon.pcapng` 抓包均来自 3.3.3.3 族大厅/入口环境，无 3.9.9.7 抓包。
- 缺少的文件：目标版本的首个有效包、服务端响应、客户端下一包等 socket/UDP 字节样本。
- 最小解除证据：目标客户端与服务器之间的一条真实会话 pcap/socket trace。
- 影响：无法确定目标版本的握手顺序、包长与字段宽度。

### BLK-007-04 — 3.9.9.7 函数级定位缺失（P0）

- 结论：现有函数级定位（Demonware 分派器、codec、帧读取器、snapshot writer）分别属于 2.6.9.7 与 3.3.3.3 族。
- 缺少的证据类型：目标版本初始化阶段、gamestate/configstring 消费、snapshot 消费的函数级反汇编。
- 最小解除证据：在目标客户端上定位 `0x03`/`0x04`/`0x06` 消费者与 snapshot delta 解码入口。
- 影响：无法闭合“服务端写入 ↔ 客户端消费”对应关系。

### BLK-007-05 — 3.9.9.7 运行时 dump 缺失（P0）

- 结论：本机仅有 3.3.3.3 族主 DLL 的运行时镜像（`codoMP_client_shipRetailBase.image.bin`）与 2.6.9.7 的静态恢复镜像，均非目标。
- 最小解除证据：目标客户端运行时解包内存镜像，且与目标文件身份可关联。
- 影响：加壳镜像的静态字节不能代表运行时映射，无法核验目标 RVA。

### BLK-007-06 — 3.3.3.3 版本归属仍为 PROBABLE（P1，辅助）

- 结论：3.3.3.3 归属来自外部 ol-mod 仓库声明与 FileVersion 1649370；二进制内无 `3.3.3.3` 串。
- 影响：即使作为学习样本，其版本标注也不能升级为 CONFIRMED，不能作为目标推导的强依据。

### BLK-007-07 — 2.6.9.7 恢复镜像运行时等价性未证（P1，辅助）

- 结论：`codol2697-static-candidate.bin` 为 aplib 静态恢复镜像，非运行时 dump。
- 影响：其上定位的地址是否等价于运行时映射仍未闭合（既有 BLOCKED）。

## 3. 解除顺序（建议）

1. **先解除 BLK-007-01 / 02**：取得并核验目标样本身份。
2. **再解除 BLK-007-05**：获得目标运行时镜像，核验 RVA 与模块信息。
3. **再解除 BLK-007-03 / 04**：取得目标抓包并定位消费链函数。
4. 最后才允许讨论 snapshot 边界、delta 与实体规则。
5. **BLK-007-06 / 07** 属辅助版本阻塞，可用于提出假设，不能直接产出 3.9.9.7 结论。
