# E21 与已知 CODOL 路径交叉验证

## 候选对照

| 候选 | 与 HMAC 对象的可证关系 | 裁定 |
|---|---|---|
| 0xA2660 Configstring reader | 无直接/静态调用边 | 未连接 |
| 0xA2E50 消息读取候选 | 无直接/静态调用边 | 未连接 |
| 0x350170 demo 顶层分派 | 无 | 未连接 |
| 0x3547D0 demo 子帧循环 | 无 | 未连接 |
| 0x354100 子帧分派器 | 无 | 未连接 |
| 0x3524F0 环形缓冲写 | 无 | 未连接 |
| 0x352570 环形缓冲读 | 无 | 未连接 |
| 0x6ABBC0 Demonware 帧头读取 | 上游同属帧状态机；不能证明游戏协议 | 强关联 Demonware |
| 0x6ABE80 接收状态机 | 状态 2 调用 0x6A9920；状态 3 调用 0x6AC0C0 | 强关联 Demonware |
| 0x6A9920 类型/载荷读者 | 直接构造 0x6A84E0 对象 | PROVEN |

## 层级纪律

必须区分以下五层，不得合并：

1. 4 字节长度前缀帧（Demonware）
2. 内部类型码 1/2（Demonware）
3. Gamestate 子帧类型（demo/replay 候选）
4. 游戏消息 opcode
5. Configstring body 字段

本次证据只支持第 1、2 层与 HMAC 对象有直接关系；第 3、4、5 层未建立连接。
