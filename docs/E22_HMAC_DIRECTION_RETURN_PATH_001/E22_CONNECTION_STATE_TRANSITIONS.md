# E22 连接状态转换

## 字段映射

| 偏移 | 含义 | 读取/写入 |
|---|---|---|
| +0x9C | 接收状态 | 0x6AC3AA 清零 |
| +0xAC | 帧长 | 0x6AC148 读取 |
| +0xB0 | 载荷对象 | 0x6AC13D 读取 |
| +0xC8 | 连接状态 | 0x6AC0EA/0x6AC10E 读取 |
| +0x5CC | 消息/会话类型 | 0x6AC178 读取 |
| +0x5D0 | 接收计数器 | 0x6AAFA4 读、0x6AAFAD 写 |
| +0x5F4 | 协商对象 | 0x6AB146 读取 |

## 状态转换

```text
+0xC8 == 4  -> 直接返回 false（连接已失败）
+0xC8 != 2  -> 跳过处理，返回
+0xC8 == 2  -> 会话主处理
   └─ 0xAAA7B0 维护
   └─ 0xAABE60 / 0xAA9570 准备
   └─ 0xA85AD0 解析（BSS，不可静态）
   └─ [0x5CC] == 1  -> 0x81 / 0x04 分支
   └─ [0x5CC] == 2  -> 0x83 / 0x84 分支
   └─ [0x5CC] == 3  -> 0x85 分支 -> 0x6AAE70
```

## 失败处理

`0x6AAE70` 失败时调用 `0xAAA770`：

```asm
6AA773  mov eax,[esi+0xC8]
6AA779  cmp eax,1
6AA77C  jne 0xAAA787
...
6AA791  mov [esi+0xC8],4
```

这证明 HMAC/计数器失败会把连接状态推进到 4（失败/断开），并调用清理路径。

## 裁定

| 项 | 裁定 |
|---|---|
| 连接状态字段 +0xC8 分派 | PROVEN |
| 接收计数器 +0x5D0 递增/校验 | PROVEN |
| 失败置连接状态 4 | PROVEN |
| +0x5CC 消息码与 HMAC 路径对应 | PROVEN |
| 入站或出站方向 | INFERRED / BLOCKED |
