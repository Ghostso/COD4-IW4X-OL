## E.2 阻塞项汇总

1. **未获下载授权（阶段 B 阻塞）**：来源已审查通过，但任务明文要求“如需联网下载…先申请明确授权”。本轮**未获授权**，故未下载、未实测哈希。
2. **完整性仅有同源依据**：目标包**无独立 PGP 签名、无独立第二来源**；SHA-256/MD5 均来自 SourceForge，只能防传输损坏，**不能**称“已被密码学认证”。
3. **包结构未审查（阶段 C 阻塞）**：`windres.exe` / `mingw32-make.exe` 是否随包提供，**在阶段 C 前只能是 CANDIDATE**，不得当作事实。
4. **NASM 版本未定**：CI 默认 **2.16.01**，本机缓存为 **3.01**，两者不同；采用 3.01 属**未验证偏离**。
5. **本机已有环境不足以产出工具链**：无 `C:\msys64`、无 i686 MinGW、无 `7z.exe` 在 PATH（仅有非 PATH 的 7-Zip 副本）、无 `nasm`。
6. **工具链未运行**：静态包检查**不得**表述为“工具链已成功运行”；即便后续能编译简单示例，**也不等于项目能成功构建**。
