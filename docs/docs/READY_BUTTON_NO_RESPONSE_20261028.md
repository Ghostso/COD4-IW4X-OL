## 五、另一个已验证的纠正

`isroomhost` / `team` / `secureProfileReady` 挨着 `getchallenge` / `connect %s "%s"` /
`stats` / `heartbeat` —— 这是**战斗服 connect 命令的参数表**，
是客户端连 28960 时发出去的身份标志，**不是 UI 状态变量**。

此前把它们当作 UI 依据是错的。

## 七、下一步的可行方向

1. **查 `.ifs` 里的 UI 定义**——按钮的可用条件可能写在 UI 资源里。
   但项目既有结论：`.ifs` 载荷是加密的（971/974 个），只能解出头部/清单。
2. **让用户提供更精确的现象**：按钮是否有 hover 效果、按下有无音效、
   界面其它元素（地图、队伍列表）是否正常显示。
   —— 如果整个房间界面的动态部分都不动，说明是房间数据没喂进去；
      如果只有按钮不响应，那是按钮绑定问题。
3. **对照 10-26 那轮**：那轮客户端能连战斗服，但它是 PvE 剧情入口，
   从未进过 BOT 房间 UI。也就是说**我们从来没有见过这个房间界面正常工作的样子**。
