# ui_mp.ff 探测：文件加密，Flash 资源不可达（2026-10-28 第十八轮）

## 一、目标

用户观察「点准备没反应」。上一轮确认房间 UI 是 Scaleform（Flash），
按钮对应 `AS_SetReadyState` 等类。本轮试图从 `ui_mp.ff` 里取出
Flash 资源，看按钮绑了什么。

## 二、结果：文件整体加密

`COD OL\main\ui_mp.ff`，29,224,001 字节。

### 头部

```

cd 01 00 00               461          version  ← 加载工具不认这个版本
01 00 00 00               1
```

### 熵值抽样（判定加密/压缩）

| 区域 | 偏移 | 熵 | 可打印 |

### SWF/GFX 签名扫描

## 三、对照：已知的 `ui_mp.txt` 清单

`EARLY_SERVER_ANALYSIS/13_NATIVE_TAP_BUILD_001/experiment_copy/docs/zone_assets/ui_mp.txt`
（2599 行）内容形如：

```

...

```

这是**素材清单**（material 名），不是菜单/脚本定义。
没有 menu、gfx、menufile 项 ⇒ 拿不到按钮绑定。

## 四、因此得出结论

`ui_mp.ff` 加密 ⇒ **Flash 资源不可达**。

`.ff` 这条路关闭。

## 六、诚实评估

**目前没有任何一条可执行的路径能确定「准备按钮为什么点不动」。**

已知的全部事实：
1. 点击不产生任何网络上行（已实证）
2. 本地 UI 状态也不变（用户观察）
3. 房间 UI 是 Scaleform，按钮对应 `AS_SetReadyState`
4. 该类名在内存中无 COL、无引用

推论（**未证实**）：`AS_*` 处理类未被注册到 Scaleform，
导致 Flash 的按钮回调找不到后端，点击被静默丢弃。
